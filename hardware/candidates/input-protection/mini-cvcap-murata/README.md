# MINI CVCAP / Murata — инженерный DRAFT

Это отдельный проверенный снимок входного кандидата, не замена основной платы и не выпуск для заказа. Актуальная схема — `native/input_protection_MINI_DRAFT.kicad_sch`; проверенный PDF — `render/input_protection_MINI_DRAFT.pdf`.

## C1

- Value: `220nF 50V C0G 5%; VCAP-ANODE`.
- MPN: `GRM31C5C1H224JE02L`.
- Footprint: `Sirokko_Input:Murata_GRM31C5C1H224JE02L_Reflow`.
- C1.1 и U1.1: `/VCAP_LOCAL`; C1.2 и U1.6 ANODE: `/VIN_FUSED`. Это НЕ конденсатор на GND.
- Предметная библиотека находится только в этом отдельном кандидате: `native/Sirokko_Input.pretty/`. Значение, MPN и соединения инженера сохранены.

Посадочное место сверено с [Murata, GRM31C5C1H224JE02-01A](https://pim.murata.com/asset/pim4/ceramicCapacitorSMD/GRM31C5C1H224JE02-01A-EN_PDF_CERAMICCAPACITORSMD), стр. 27, Table 2, Reflow, GRM31 3.2×1.6 within ±0.20. Допустимые a/b/c: 1.8…2.0 / 0.9…1.2 / 1.5…1.7 мм. Выбраны 1.9 / 1.1 / 1.6 мм; центры площадок ±1.5 мм, каждая 1.1×1.6 мм, наружный размер меди 4.1 мм. Стр. 6 с испытательным шаблоном не использовалась вместо reflow-рекомендации. Полный сторонний PDF не включён; SHA256 прочитанного оригинала: `0cf9274b6ce7c12de1f31e27bbf01d8cda86c9aa79a0a6b03c85fab8617be6ae`.

## Реальные проверки KiCad 10.0.7

- Штатное чтение `pcbnew`, повторное чтение платы и независимое чтение MCP: 2 SMD roundrect-площадки на F.Cu/F.Paste/F.Mask, площадки и вся конструктивная геометрия совпадают с инженерным исходником.
- Финальный изолированный DRC: exit 0, 0 нарушений, 0 непроложенных, `ignored_checks=[]`; все уровни нарушений включены. Это проверка одного посадочного места без электрических сетей, НЕ проверка полной схемы на PCB.
- Сначала исходная надпись REF** при y=−1.6 мм воспроизводимо дала `silk_overlap` (1 warning, exit 5). Инженер разрешил исправление исходника: только REF** y=−1.6→−1.9 мм. Площадки, медь, маска, паста, дворик и обязательная графика не менялись и не удалялись. До/после сохранены в `reports/history/footprint-before-reference-fix-drc.json` и `reports/reference-position.diff`. Правила не подавлялись.
- Свежий ERC схемы до/после: 0/0, `ignored_checks=[]`.
- Все четыре XML — до выбора номинала, после выбора номинала, до назначения предметного footprint и финальный — имеют одну полную карту: 23 вывода, 6 сетей, 0 изменений. Проверены ВСЕ выводы, не только C1. Сравнение: `reports/full-pinmap-diff.csv` и `.json`.
- XML всех шести компонентов, кроме C1, до/после побайтно одинаков. В том числе D1 остаётся `SMCJ28CA`; SMCJ33CA не назначен.
- Новый BOM содержит 7 компонентов и отдельные столбцы MPN/Footprint/Qualification. Финальный XML и BOM содержат точный Murata footprint, не generic C1206.
- В актуальном примечании схемы больше нет старого номинала C1 100 nF. PDF осмотрен: новое примечание читается, не обрезано; прежнее наложение подписей U1/Q1/C1 в центре листа не исправлялось. Соединения подтверждены XML, не видом PDF.
- PNG посадочного места осмотрен. Для PNG расширены только границы холста штатного SVG, чтобы целиком показать Value; векторы и native-геометрия не менялись. Исходный SVG экспорта сохранён отдельно.

Python-модуль `pcbnew` при инициализации печатает диагностические сообщения `PROPERTY_ENUM(): No enum choices defined`; чтение и проверки завершились, а штатные CLI ERC/DRC/экспорты имеют явно сохранённые коды возврата в `reports/*-commands.json`.

## Что НЕ готово

PCB `native/input_protection_MINI_DRAFT.kicad_pcb` сохранена побайтно: на ней только F1. C1 назначен в схеме, но НЕ добавлен на эту PCB. Свежая проверка соответствия схеме сохраняет 2 ошибки непроложенных соединений и 6 предупреждений `missing_footprint` (C1/D1/J1/J2/Q1/U1); обычных геометрических нарушений 0. Отчёт: `reports/candidate-parity-drc.json`. Ни основная PCB, ни SPI-кандидаты не изменялись.

Физическая примерка, реальная пайка Murata, запуск и измерение VCAP−ANODE/reverse-blocking на стенде остаются невыполненными. Murata требует проверить пригодность площадок на фактической PCB. Тепловая и время-токовая квалификация F1 не завершены. D1 сохранён по границе этой работы, а не принят как готовое решение: выбор TVS остаётся открытым выпускным вопросом; SMCJ33CA не принят, форма и энергия импульса внешнего БП не установлены. Не использовать этот снимок для изготовления/заказа или как подтверждённую защиту.

Расчёт Cmin 208.373 nF из [отчёта подбора](../LM74700Q1_CVCAP_selection_2026-10-25.md) относится к +25…+125 °C. Ниже +25 °C инженер отдельно проверил паспортные точки Table A; формула не объявляется непрерывной гарантией всего температурного диапазона и не включает последствия монтажа/ресурсных испытаний.

## Повторная штатная проверка

Из корня этого каталога при установленном KiCad 10.0.7:

```sh
sha256sum -c SHA256SUMS
kicad-cli sch erc --format json --severity-all --exit-code-violations -o /dev/stdout native/input_protection_MINI_DRAFT.kicad_sch
kicad-cli pcb drc --format json --severity-all --all-track-errors --exit-code-violations -o /dev/stdout validation/Murata_CVCAP_isolated.kicad_pcb
```

Для проверки полноты схемы/PCB добавить `--schematic-parity` и указать native PCB; ожидаем ненулевой код с описанными 2+6 незакрытыми пунктами. Исторические XML в `reports/history/` — только доказательство неизменности соединений, не актуальные закупочные/монтажные данные. Для текущих C1 использовать `native/`, `reports/netlist.xml`, `reports/bom.csv`.

В публичных XML и журналах служебные пути заменены относительными ссылками; native-файлы не нормализовались и не переписывались при подготовке публикации. Исходные отчёты DRC/ERC сохранены без изменения результатов.
