# Sirokko t_52190740 — замороженный инженерный handoff

Статус: **DRAFT / unified candidate prepared / layout_accepted=false / NOT FOR ORDER / NO POWER / NO FIRE**.

Публичный каталог — отдельный immutable WIP-снимок после `unified_da1962d9`, а не его замена. [Аудит публикационного состава](PUBLICATION_AUDIT_RU.md) фиксирует исходный архив, дополнение отсутствовавших дочерних листов/локальных библиотек из той же immutable-базы, очистку служебных путей, исключение внутренних `tools/` и стороннего STEP без найденного разрешения на распространение. ## 7. P24 и реле: что осталось открытым

P24:

- D20: опубликовано `13.8…15.6 В @ 5 мА / TA25°C / short pulse`;
- этот диапазон не является полной гарантией `Vz(T)` в рабочей ветви;
- расчёт 16 углов: максимум `88.767798 мВт` на один R120/R121, `110.959747 мВт` с 25% запасом;
- независимая граница `Pz ≤ 95.673028 мВт` действует только при `rail≤45 В`, исправных последовательных резисторах и пассивной ветви;
- остаются открыты: реальный clamp, ток D20 с вычитанием ветви R123, температура, монтаж и thermal derating, timing/brownout/recovery/bench validation.

Реле/DRV:

- coil option: exact `1024`, без `R/DR/D`, `305 Ом ±10% @23°C`;
- модель бюджета: 200 мА/channel; расчёт `139.443 мА ×1.3 = 181.275 мА`;
- `DRV8803` и 330 мкФ сохранены;
- для `0.6 А / 100 мкс` расчётный минимум 187.5 мкФ; условные 198 мкФ дают 0.40303 В;
- temperature/ESR/clamp и физическая релейная сборка остаются открыты.
