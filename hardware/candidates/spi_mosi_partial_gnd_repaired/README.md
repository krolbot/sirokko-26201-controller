# Sirokko — частичная MOSI U9–TFT с восстановленной GND

WIP / DRAFT / NOT_FOR_ORDER / НЕ ДЛЯ ЗАКАЗА И ОГНЕВЫХ ИСПЫТАНИЙ.

Это отдельный промежуточный снимок, а не законченная общая плата. Проложен только участок MOSI `U9.12 ↔ J26.4` (TFT); `U10.12` и `J1.17` остаются раздельными и неразведёнными. Полная MOSI не завершена.

## Сохранённые инженерные проверки

В замороженном комплекте использован KiCad 10.0.7: штатные `pcbnew` `ZONE_FILLER.Fill`, `BuildConnectivity`, `GetConnectedItems` и `kicad-cli pcb drc --refill-zones --format json --severity-all --all-track-errors`.

- [Полный DRC](mosi_gndrepair_full_drc.json): четыре прежних предупреждения `lib_footprint_mismatch` для J23/J24/J25/C1, 171 неразведённое соединение, пять прежних `ignored_checks`. Нет новых нарушений зазоров, коротких замыканий, пересечений дорожек или висячих переходов среди включённых проверок. Это не чистый DRC и не проверка схемной эквивалентности.
- [Штатная проверка связности](native_connectivity.json): GND `U9.1/U9.14/C9.2/C10.2/C13.2` — одна проводящая группа; SCK `U9.10/U10.10/J1.18/J26.5`, MISO `U9.11/U10.11/J1.19`, EXH_DRDY `U9.7/J3.4` и AIR_DRDY `U10.7/J3.5` сохранены. MOSI `U9.12/J26.4` связана; `U10.12` и `J1.17` не соединены.
- [Попарная карта GND](gnd_pairwise_map.json) и [реестр изменений геометрии](geometry_change_register.md) сохраняют диагноз отклонённой версии: локальная дорожка MOSI на F.Cu разрезала связь острова C13.2 с U9/C9/C10. В исправленной версии локальный обход перенесён на B.Cu, без изменения правил или добавления произвольного перехода GND.

При публикации проверены целостность архива и всех 16 исходных контрольных сумм, неизменность PCB/проектных правил/DRC и содержимое отчётов. Инфраструктурный абсолютный путь в `native_connectivity.json` заменён только относительным именем PCB. Инженерные проверки повторно здесь не запускались; публикуются сохранённые результаты для точного SHA платы выше.
