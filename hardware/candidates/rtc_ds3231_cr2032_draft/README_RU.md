# Sirokko — RTC DS3231 / CR2032, схема-кандидат

Статус: DRAFT / NOT FOR ORDER. Это законченный локальный лист RTC для последующей интеграции, НЕ законченная плата контроллера и НЕ испытанный узел.

## Что сделано

- В KiCad создан лист `RTC_DS3231_CR2032_DRAFT.kicad_sch`: U9201 DS3231SN+, BT9201 под CR2032/Keystone 1060, два конденсатора 100 нФ и две подтяжки I2C 4,7 кОм ±1%.
- Питание VCC — только +3V3; батарейная сеть VBAT_RTC содержит только плюс батареи, C9202 и U9201.14. Зарядных цепей нет. RTC RST/INT/32kHz не подключены к MCU или аппаратной защите.
- Номера DS3231SN+ независимо сверены с таблицей изготовителя, а не только с именем библиотечного символа DS3231M: VCC=2, VBAT=14, SDA=15, SCL=16, GND=13; выводы 5–12 также должны быть на GND. Все эти выводы действительно присутствуют на GND в экспортированном netlist.
- Назначены footprint всем шести деталям листа. SOIC-16W и держатель остаются кандидатами до окончательной закупочной/механической квалификации.
- Создан отдельный проверочный корневой проект `RTC_INTEGRATION_FIXTURE_NOT_PCB.kicad_pro`. Его J9201 лишь представляет внешний источник +3V3/GND и интерфейс MCU: его НЕ переносить на основную PCB. Порядок J9201: 1=+3V3, 2=GND, 3=RTC_SDA, 4=RTC_SCL.
- ERC корневой проверочной иерархии KiCad 10.0.7: 0 ошибок и 0 предупреждений. Полный JSON включён. Четыре стандартных ignored_checks перечислены в нём; новые исключения не добавлялись. PWR_FLAG на корне представляет внешний источник и его возврат; флаг VBAT — физическую батарею с пассивными контактами стандартного символа. Это не доказательство наличия питания на будущей общей плате.
- После правок читаемости весь словарь `(reference,pin) -> net` сохранён: 30/30 соединений идентичны до/после. PDF повторно экспортирован и осмотрен.

## Интерфейс и проверка подтяжек

Порты будущего дочернего листа: +3V3, GND, RTC_SDA (двунаправленный), RTC_SCL (вход). GPIO ESP32 в этой итерации НЕ назначены; существующий контракт прошивки не изменён.

Инженерный выбор: I2C Standard mode 100 кГц. Расчётные условия, ещё требующие проверки на общей плате: шина 3,3 В ±5%, Cbus не более 150 пФ на линию, без дополнительных параллельных подтяжек. Для R=4,7 кОм ±1%:

- Rmin=4653 Ом, Rmax=4747 Ом, Vmax=3,465 В.
- I_LOW при VOL=0,4 В: (Vmax−0,4)/Rmin = 0,659 мА. Верхняя граница при VOL=0: Vmax/Rmin = 0,745 мА; с коэффициентом 1,30 это меньше паспортного IOL=3 мА.
- tr(30–70%) = 0,8473 × Rmax × Cbus = 603 нс. При Cbus × 1,30: 784 нс, меньше 1000 нс для Standard mode из таблицы DS3231. Это НЕ разрешение переключить интерфейс на Fast mode, где предел 300 нс.
- P_Rmax=Vmax²/Rmin = 2,580 мВт; с коэффициентом мощности 1,25 требуется не менее 3,225 мВт. Точный закупаемый резистор квалифицировать по его температурному снижению мощности.

Эти вычисления не подтверждают запас 30%/25% для всего изделия. Допуски питания MCU не понижать ради формального коэффициента. Проверить реальную ёмкость/фронты и уровни обеих линий после трассировки.

## Что ещё не выполнено

- Лист не включён в основную схему Sirokko и не перенесён на общую PCB; разместить и развести RTC ещё предстоит.
- Не подтверждена карточка DS3231SN+ у ChipDip: поиск не дал точного результата, сайт в браузере вернул DDoS-Guard. Не считать отсутствие результата отсутствием детали в каталоге. MPN/корпус, современные условия паспорта, пассивные детали и номиналы/утечки C9202 требуют закупочной квалификации.
- Keystone 1060: ранее найденная карточка https://www.chipdip.ru/product/8049467254 ; наличие/цена в этой итерации не проверены.
- Прошивка не изменена: необходим драйвер RTC через существующий автомат, проверка OSF/достоверности даты и запрет использования недостоверного календаря. Длительности защитных этапов остаются монотонными. Батарейка и календарь не разрешают продолжать старый RUN или автоматически разжигать отопитель после возврата питания.
- Нет измерений тока батареи, обратного питания, переходов VCC/VBAT, отсутствующей/перевёрнутой батареи или точности хода. Ёмкость CR2032 и срок службы здесь не выдумываются.
- Нулевой ERC проверочной иерархии не заменяет ERC/F8/DRC основной платы, измерения и приёмку всего контроллера.
