## Исходный объединённый этап

Принят перенос SPI в моторную копию из t_dca0bca5: PCB SHA256 `c07f85759c0d576fd15368ce58ce58a5ecfc62815af4000639d3d0de3641aadc`. 112 посадочных мест, 426 физических площадок, 402 схемные записи вывод→сеть, 194 сегмента, 52 перехода. Геометрия компонентов, назначение площадок и моторный контур сохранены; J20/J21 удалены ранее.

Сохранённая штатная проверка KiCad 10.0.7 подтверждает восемь групп SPI/GND: MOSI, SCK, MISO, обе CS и DRDY термопар и заданную группу земли. Инженер повторил эту приёмку с кодом 0. Это проверка перечисленных связей, не общий PASS платы. При публикации инженерные проверки заново не запускались.

Полный DRC: **225 неразведённых соединений**, **4 прежних lib_footprint_mismatch warnings** и **5 прежних ignored_checks**; новых подавлений не добавлено. ERC исходной иерархии — 0 нарушений при сохранённых настройках, с четырьмя ignored_checks. Полные исходные JSON, перечень исключений, native acceptance, сверка 402 связей и root netlist находятся в `reports_t_dca0bca5/`. Эти отчёты относятся только к исходному объединению. Служебный путь источника внутри XML — исторические метаданные экспорта, не другой рабочий источник.

Изображения `images_t_dca0bca5/top_full.svg/png` и `bottom_full.svg/png` относятся к этому исходному SHA, не к последующей TFT-разводке. Это CAD, не фотографии платы. Локальные суммы: `sha256sum -c SHA256SUMS` из этого каталога.
