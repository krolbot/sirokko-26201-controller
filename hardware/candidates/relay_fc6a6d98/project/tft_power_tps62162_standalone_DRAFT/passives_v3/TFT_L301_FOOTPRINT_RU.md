## Источник и размеры

Точный MPN: 744025003, WE-TPC, размер2828. Документ Würth revision002.002,2016-12-05,1/6, раздел B Recommended Land Pattern. Оригинальный URL https://www.we-online.com/components/products/datasheet/744025003.pdf в текущей попытке вернул403. Использована публичная копия документа изготовителя https://pdf.utmel.com/r/datasheets/wrthelektronik-744025003-datasheets-5306.pdf ; PDF действительно скачан, перваястраница отрисована и осмотрена. Это не заявление о последней редакции: электрический расчёт проекта ранее ссылался на002.003от2020-06-09, его электрические пределы здесь не пересматривались. СтороннийPDFвпакет/Gitне включён.

Корпус2.8±0.2mm поX/Y/Z. Габарит используемого упрощённого F.Fab2.8×2.8mm — охватывающий квадрат, не точная3Dмодель скосов корпуса. В чертеже метaллизация компонента имеет0.9/1.0/0.9mmtyp; это НЕ медьPCB.

Рекомендованная медьPCB: два прямоугольника1.0×3.2mm с внутренним зазором1.2mm. Библиотечное соглашение: pad1слева, pad2справа; изделие неполярное, отдельный знак начала обмотки в источнике не указан. Номера при дальнейшем переносе сохранять для неизменности pin→net: в отдельной схеме L301.1=SW, L301.2=TFT_3V3.

Расчёт координат, выполненный инструментом: pitch=1.2+1.0=2.2mm; центры(−1.10;0) и(+1.10;0); полныйгабаритмеди3.20×3.20mm. F.CrtYd3.70×3.70mm: max(3.0mmмаксимальныйкорпус,3.2mmмедь)+2×0.25mm. Запас0.25mmназначенинженерно; этонедопусккорпуса. Mask/pasteнаследуютсяотбудущегопроекта, процесс/трафареттребуютсогласованиясизготовителем.

В установленной библиотеке найден только L_Wuerth_WE-TPC-3816; его нельзя использовать по совпадению серии вместо2828. Поэтому создано предметное посадочное место по точному чертежу.
