Выполнено через штатный pcbnew существующего KiCad10.0.7:

Правило pads не запрещает собственныеNPTH; отсутствие ЧУЖИХ площадок внутри каждой области дополнительно проверено консервативно по bounding box каждой площадки — пересечений0. Основание размеров защитной области — назначенная конструктором спецификация допустимого крепежа, НЕ паспорт выбранногоMPN: максимальный поперечный габарит головки/шайбы/стойки5.0мм; минимальный диаметр стержня1.8мм; максимальный диаметр готового отверстия2.8мм (дляØ2.7 назначен допуск±0.1мм); технологический зазор до меди0.5мм. Требуемый радиус:5/2+(2.8−1.8)/2+0.5=3.5мм. Вписанный радиус3.59566мм больше требуемого.
