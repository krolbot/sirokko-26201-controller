# Посадочные места конденсаторов питания TFT Sirokko

**DRAFT / NOT FOR ORDER / НЕ ДЛЯ ОГНЕВЫХ ИСПЫТАНИЙ**

Статус: геометрия трёх посадочных мест проверена штатным KiCad 10.0.7. Это библиотека для четырёх компонентов отдельного review-узла TPS62162, а не изменение основной PCB или разрешение производства. Монтаж — оплавлением. Схема, её Footprint-поля, root PCB, BOM и firmware в этой работе не менялись.

## Основание и выбор

Источник монтажной геометрии: Murata, reference sheet точного C304 GRM32ER61C476KE15L, 2021-07-01, p.26, раздел Soldering and Mounting, Design 2, **Table 2 Reflow Soldering**. Это рекомендация монтажа, а не размеры испытательной подложки Table1 на p.22. Рисунок на p.26 проверен визуально: a — внутренний зазор между площадками, b — длина одной площадки по X, c — ширина по Y.

Документ: https://static.chipdip.ru/lib/039/DOC028039487.pdf . Дополнительный reference sheet C301/C302: https://static.chipdip.ru/lib/630/DOC011630562.pdf . Brief specifications: C301/C302 https://static.chipdip.ru/lib/915/DOC030915783.pdf ; C304 https://static.chipdip.ru/lib/349/DOC030349279.pdf ; C303 https://static.chipdip.ru/lib/811/DOC021811649.pdf . Сторонние PDF в пакет и Git не включены.

Проверенные краткие спецификации:
- C301/C302: GRM21BR61E106KA73L, 2.0 ±0.15 × 1.25 ±0.15 mm.
- C303: в полном XML схемы записан **GRM188R71E104KA01D**, его сохранять. Прежнее указание L по brief specification и фраза «не заменять ... на D» были ошибочны и отозваны. В текущей v3 найден и визуально прочитан точный исторический лист Murata GRM188R71E104KA01#, 2017/09/27,1/1: D/J явно входят в список MPN; L/W/T=1.6±0.1/0.8±0.1/0.8±0.1 mm, terminal e=0.2…0.5 mm,g≥0.5 mm. D=бумажнаялентаØ180mm. Источник: https://datasheet4u.com/datasheets/Murata/GRM188R71E104KA01D/1151275 ; прочитанное изображение документа https://datasheet4u.com/pdfhtml/0389/1151275/page-000001.png . Геометрия D подтверждена, следовательно подходит уже выбранная строка Table2 GRM18 1.6±0.1×0.8±0.1; .kicad_mod не изменён. В историческом листе есть «Please use replacements or Recommended.»: это предупреждение статуса/закупки, не текущий склад и не указание конкретной замены. Доступность актуальной партии проверять перед закупкой; этот лист не объявлен текущей спецификацией или разрешением менять MPN.
- C304: GRM32ER61C476KE15L, 3.2 ±0.3 × 2.5 ±0.2 mm.

Штатные KiCad C_0805_2012Metric, C_0603_1608Metric и C_1210_3225Metric были прочитаны, но для этого узла выбрана медь непосредственно по рекомендации Murata для оплавления. Отличие общего библиотечного footprint само по себе не означает его непригодности. Выбор ниже не делался ради обхода DRC.

## Назначенные размеры

Все размеры в mm. Центры площадок x=±(a+b)/2, y=0; pad1 слева, pad2 справа. Конденсаторы неполярные; нумерация нужна для сохранения pin→net.

- C301/C302: `Sirokko_TFT_Passives:C_Murata_GRM21B_2012_Reflow`; a=1.20, b=0.70, c=1.30; центры x=±0.95. Строка Murata для 2.0±0.15 ×1.25±0.15: a=1.2, b=0.6…0.8, c=1.1…1.4.
- C303: `Sirokko_TFT_Passives:C_Murata_GRM188_1608_Reflow`; a=0.70, b=0.65, c=0.80; центры x=±0.675. Строка Murata для 1.6±0.1 ×0.8±0.1: a=0.6…0.8, b=0.6…0.7, c=0.6…0.8.
- C304: `Sirokko_TFT_Passives:C_Murata_GRM32E_3225_Reflow`; a=2.20, b=1.10, c=2.20; центры x=±1.65. Строка GRM32 для 3.2×2.5: a=2.0…2.4, b=1.0…1.2, c=1.8…2.3.

F.Fab показывает номинальный корпус. F.CrtYd охватывает максимальные габариты корпуса и медь с назначенным инженерным запасом 0.25 mm на сторону; этот запас не является допуском размеров детали. Замкнутые courtyard: 3.10×1.90, 2.50×1.40 и 4.90×3.20 mm соответственно. Площадки прямоугольные, F.Cu/F.Paste/F.Mask. Параметры маски/пасты наследуются от будущего проекта и отдельно согласуются с изготовителем; толщина трафарета здесь не назначалась. Внешняя шелкография корпуса не добавлена, Reference вынесен за courtyard.

## Фактические проверки

1. Все три .kicad_mod прочитаны KiCad MCP; площадки и их размеры совпали с назначенными.
2. pcbnew.FootprintLoad в действующем KiCad 10.0.7 повторно прочитал три файла. Нативно проверены номера 1/2, центры, равенство размеров площадок и попадание a/b/c в соответствующую строку Murata. Код завершения 0; локальные и удалённые SHA256 всех трёх файлов совпали.
3. Негативная числовая проба: неверный зазор C304 a=0.5 mm при прежних b/c отклоняется проверкой диапазона. Исходные файлы не изменялись.
4. Выполнен штатный SVG-экспорт трёх Murata footprints. В текущей v2 превью добавлено только поле страницы 0.8 mm; все векторные элементы сохранены. PNG пересобраны без прежней принудительной высоты, сохраняют соотношение сторон SVG и повторно осмотрены: две раздельные площадки, замкнутые F.Fab/F.CrtYd, подписи не перекрывают металл, видны целиком с полями. Номера площадок не отображаются в SVG; проверены нативным чтением, не по картинке. Изменение полей страницы/пропорций превью не меняло .kicad_mod.
5. При запуске pcbnew окружение вывело три диагностических assert PROPERTY_ENUM / No enum choices defined. Они полностью сохранены в JSON; процесс завершился 0, все footprint-объекты прочитаны. Штатный отдельный CLI SVG-экспорт успешен. Это **не** заявление об отсутствии диагностик окружения и не исправление KiCad.

Полный числовой результат: `TFT_MURATA_PASSIVE_FOOTPRINT_ACCEPTANCE.json`. Контрольные суммы — `SHA256SUMS` в пакете.

## Границы приёмки

Проверена только геометрия библиотеки. Не подтверждены effective capacitance/DC bias, L(I,T), тепловой режим TPS62162, общий бюджет 5 V, пуск и переходные режимы, EMC и пайка реального образца. Нет назначения этих мест экземплярам схемы, нет интеграции в основную PCB и нет DRC законченного изделия. Первоначально пустые восемь Footprint-полей review-схемы этой работой не заполнены. Остальной U301 требует собственной квалификации посадочного места; геометрия L301 описана отдельно в TFT_L301_FOOTPRINT_RU.md, R301/R302 — в TFT_R301_R302_FOOTPRINT_RU.md. Эти геометрические проверки не означают электрический допуск узла. Общая разводка и firmware остаются на HOLD до приёмки компоновки.

Для последовательной публикации использовать этот замороженный набор с его SHA256, не копировать сторонние PDF, не изменять чужой активный лист параллельно с его единственным писателем.
