## Геометрия и ограничения

Новые сигнальные дорожки имеют ширину 0,25 мм, земляные 0,5 мм; обычные сквозные переходы 0,6/0,3 мм. Переходы использованы для обхода прежних сетей и земляных перемычек без ослабления правил. Трассы команд обошли измерительный узел справа; прямого прохода через Kelvin-площадки нет.

По native-геометрии добавленные длины FAN_REQUEST/SPEED_CMD: 201,398/195,352 мм, переходов 9/11. Это длинные WIP-маршруты. Частота PWM сама по себе не доказывает качество фронтов; SI, возвратные токи, излучение, перекрёстные помехи и поведение при включении не квалифицированы. Дальнейшая приёмка может потребовать перекомпоновки, сокращения трасс или обоснованного согласования. Геометрический PASS не разрешает считать такое решение окончательным.
