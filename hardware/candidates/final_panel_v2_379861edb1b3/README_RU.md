Состояние по сохранённым проверкам KiCad 10.0.7: DRC — 0 ошибок, 12 предупреждений, 84 незавершённых соединения; ERC — 0 ошибок, 11 предупреждений. В отчётах также сохранены 5 исключённых проверок DRC и 4 ERC. Это не общий PASS для изготовления; при публикации KiCad-проверки повторно не запускались.

Окно TFT и `z_front` остаются HOLD: перед выпуском корпуса нужна контрольная сборка TFT + выбранная колодка J26 + четыре M2-опоры, измерение высоты передней поверхности и положения активной области. Пунктир активной области на макете не разрешает вырез окна. После механической приёмки требуется отдельная доводка UI/TFT-сетей и повторные проверки; общую автотрассировку не запускать.
