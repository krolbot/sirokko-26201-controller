## Сохранённые инженерные проверки

Автор снимка выполнил проверки штатными средствами KiCad 10.0.7: `pcbnew` `ZONE_FILLER.Fill`, `BuildConnectivity` и `GetConnectedItems` от **каждой** целевой площадки. [Отчёт связности](parent_MOSI_all_four_native_acceptance.json) привязан к указанному SHA256 PCB; все группы подтверждены:

- MOSI: `U9.12 / U10.12 / J1.17 / J26.4`;
- GND: `U9.1 / U9.14 / C9.2 / C10.2 / C13.2`;
- SCK: `U9.10 / U10.10 / J1.18 / J26.5`;
- MISO: `U9.11 / U10.11 / J1.19`;
- EXH_DRDY: `U9.7 / J3.4`; AIR_DRDY: `U10.7 / J3.5`;
- EXH_CS: `U9.9 / J1.16`; AIR_CS: `U10.9 / J1.15`.

[Полный DRC](parent_MOSI_all_four_connected_drc.json) получен через `kicad-cli pcb drc --refill-zones --format json --severity-all --all-track-errors`:

- четыре прежних `lib_footprint_mismatch`: J23/J24/J25/C1;
- **169 неразведённых соединений** — это не чистый DRC всей платы;
- пять прежних `ignored_checks`: `missing_courtyard`, `track_not_centered_on_via`, `tuning_profile_track_geometries`, `footprint_filters_mismatch`, `footprint_type_mismatch`;
- новых нарушений зазоров, коротких замыканий, пересечений дорожек и висячих дорожек/переходов среди включённых проверок нет. Схемная эквивалентность этим запуском не проверена.

По отчёту автора CLI завершился с кодом 0 **без** `--exit-code-violations`; этот код не означает отсутствие нарушений. Проверка связности с `assert` всех групп завершилась с кодом 0. Известные сообщения `PROPERTY_ENUM` действующего `pcbnew` не скрывались; зависимость не исправлялась.

При публикации проверены SHA256 архива/PCB, побайтная сохранность всех исходных файлов, состав и взаимная согласованность отчётов, неизменность проекта и прежних снимков.
