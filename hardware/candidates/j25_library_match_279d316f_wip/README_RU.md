## Изменение

В существующем J25 `TerminalBlock_Phoenix:TerminalBlock_Phoenix_MKDS-1,5-4-5.08_1x04_P5.08mm_Horizontal` исправлены только четыре угла площадок: 0° → 180°, как у штатного библиотечного посадочного места при повороте корпуса 180°. Сравнение нативно загруженного штатного library footprint с J25 показало различие только этих углов среди сравниваемых свойств площадок. Три площадки круглые, первая — центрально-симметричный квадрат со скруглениями; размеры 2,6×2,6 мм, отверстия Ø1,3 мм, смещения shape offset нулевые. Поворот 180° не меняет занимаемую медью площадь. Размеры, bounding boxes, центры, номера, сети и UUID сохранены. Точный diff — четыре строки `(at ...)`, других изменений файла нет.

Контакты J25 по нативной PCB: 1 = +3V3; 2 = THERMAL_OK (вход); 3 = GND; 4 = EXT_SAFETY_ENABLE (выход). Вид сверху, слева направо на данном положении платы — 4, 3, 2, 1. Внешнее возбуждение выхода 4 запрещено. Это не интерфейс комнатного датчика: DS18B20 остаётся на J12.
