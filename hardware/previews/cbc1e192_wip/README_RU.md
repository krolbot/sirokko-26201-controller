## Получение и проверка
KiCad10.0.7, kicad-cli pcb export svg --mode-single --page-size-mode 2 --exclude-drawing-sheet --check-zones, с явным выбором слоёв; для нижней стороны --mirror. Оба запуска exit0, stderr пуст. SHA PCB до и после экспортов одинаков. Для PNG применён уже установленный rsvg-convert, ничего не устанавливалось.

Первый MCP-экспорт выводил A4 с рамкой, недостаточной для полного контура платы. Он не включён в выдачу. Повторный штатный CLI-экспорт выполнен по всей плате без рамки. В итоговом SVG добавлено поле с сохранением координат всей геометрии: исходный plot-page мог подрезать самую кромку Edge.Cuts. Проверены все четыре прямолинейных участка контура: исходные координаты (-5;10)…(330;180) мм, размер по осевым линиям335×170мм. Контур, заголовки и предупреждения итоговых PNG визуально осмотрены, не обрезаны.

Ориентация отдельно подтверждена тремя неколлинеарными отверстиями J3.1/J1.1/J1.22: native координаты и радиусы сверлений совпали с SVG как сверху, так и снизу. Для верхнего вида Xsvg=Xnative+5,Ysvg=Ynative−10; для нижнего Xsvg=334,9752−(Xnative+5),Ysvg=Ynative−10. Это перенос/зеркалирование представления, не изменение платы. Поле и подписи не меняют масштаб геометрии SVG; PNG в чате не является печатным чертежом1:1.
