### Разъёмы и исполнения

- Две колодки DS1023-1x40 дают по два отрезка: 22 контакта для ESP32 и 9 для MAX31856. Между отрезками удаляется один контакт для пропила.
- J29 состоит из двух состыкованных DG127-5.08-02P. Вместе с J13/J20/J21 нужны пять двухконтактных блоков с шагом 5,08 мм.
- J32 — ключевая вилка DS1013-12SSiB1-B-0. Для кабеля нужна одна [розетка DS1016-12MA2BB](https://www.chipdip.ru/product/ds1016-12ma2bb-idc-12f-idc-razem-rozetka-na-ploskiy-connfly-9001534455). Распайка шлейфа — в [таблице J32](../docs/assembly.md#панель-tft-24--ec11--key0).
- U101 — K7805-1000R3 без суффикса L, вертикальный SIP-3, выход 5 В / 1 А.
- Q20/Q21 — AO3422, 55 В, SOT-23. [Документация](https://www.aosmd.com/sites/default/files/res/datasheets/AO3422.pdf) и [размеры корпуса](https://aosmd.com/sites/default/files/res/package/SOT23.pdf).
