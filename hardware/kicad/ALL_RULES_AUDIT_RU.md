# Sirokko — проверка без отключённых правил DRC

**DRAFT / NOT FOR ORDER / NO POWER / NO FLASH / NO FIRE.**

## Точная ревизия

PCB SHA256: `1a3e56e602c560094dbd2edd6c066aa0d0f7205fb0d4b3b15c99b5b8dcbcc8d4`.
Корневая SCH SHA256: `2279ad71b4287f330ffd061f1218d8d945e80ca9d2caefb1292faf162a9a3bdd`.
KiCad CLI 10.0.7. Проверены основная плата и вся иерархия корневой схемы.

## Исправления

Пять прежних DRC-проверок переведены из ignore в warning: missing_courtyard, track_not_centered_on_via, tuning_profile_track_geometries, footprint_filters_mismatch, footprint_type_mismatch. Новых исключений и понижения ошибок нет. Теперь полный отчёт DRC имеет `ignored_checks: []`.

Первый прогон с включёнными правилами нашёл пять missing_courtyard и девять footprint_filters_mismatch. У H1, H3, H11, H12, H13 добавлены окружности F.CrtYd и B.CrtYd с радиусом по осевой линии 4,25 мм и толщиной 0,05 мм; соответствующая библиотечная посадка обновлена вместе с экземплярами. Это сборочные контуры, не медь, не отверстия и не новые крепления. Они укладываются внутрь существующих двухслойных запретных областей с минимальным радиусом 5,5 мм. Принятый ранее полный габарит крепежа до R4,0 мм остаётся проектным ограничением, а не подтверждением выбранного реального винта или стойки. Новым шагом размеры крепежа не квалифицируются.

Для J10/J11/J12/J13/J27/J28/J29/C25/F1 исходные символы переоформлены в пять проектных символов библиотеки Sirokko_Interface. Изменены только библиотечные имена и фильтры допустимых уже назначенных посадок. Фильтры задают конкретные посадки, а не универсальный `*`; назначенные Footprint, MPN, pin numbers, электрические типы и графика не заменялись. Остальные экземпляры стандартных символов остаются стандартными. Правка общих стандартных кэшированных символов была отвергнута из-за новых ERC lib_symbol_mismatch; на рабочую схему этот промежуточный вариант не переносился.

## Доказательства и границы

- Свежий canonical DRC: `--all-track-errors --schematic-parity --refill-zones --severity-all --exit-code-violations`, exit 0. Нарушений, предупреждений, обрывов и расхождений PCB↔SCH нет; отключённых DRC-проверок нет.
- Свежий canonical ERC: вся иерархия, `--severity-all --exit-code-violations`, exit 0, нарушений нет.
- Native refill/save/reopen выполнен. Обратное удаление только десяти новых окружностей из сохранённой PCB в точности восстанавливает исходный файл SHA d970b9c1b05feb83a9cfbd43aa8f479989029d94e54f5e67b6c9c3ff73073b36. Значит медь, заливки, pads, отверстия, размещение и прежняя графика не изменились этим шагом. Новый обход всех физических PAD-пар не заявляется: используется более сильное для этой ограниченной правки точное восстановление всего прежнего файла.
- Полные экспортированные pin→net таблицы до/после совпали: 298 назначений. Обратная замена только выбранных symbol library ID и удаление добавленных кэшей восстанавливают исходное S-expression дерево каждого изменённого листа.
- Отрицательный контроль: прежняя PCB под теми же включёнными правилами и исправленной схемой снова дала ровно пять missing_courtyard, ненулевой exit 5. Мутация рабочей платы не сохранялась.
- Проектная библиотека действительно прочитана штатным KiCad: все пять символов экспортированы в SVG, затем выполнен чистый ERC. Наличие файла само по себе не было принято за успешную загрузку.
- Отдельный контрольный вид показывает все пять новых контуров внутри платы без очевидных пересечений. Крайние клеммы на этом вспомогательном растре обрезаны; это не итоговое изображение всей платы и не метрическая проверка.
- Gerber, Excellon и обе таблицы размещения пересобраны из текущей canonical PCB. Положение всех компонентов сохранилось; обе таблицы placement побайтно совпали с предыдущими принятыми таблицами. Сборочные окружности не входят в производственные слои. Предыдущий комплект и его DRC со списком из пяти ignored_checks не заменяют текущий отчёт.

Чтение GraphicalItems в одном из обратных native-проходов вернуло неитерируемый SWIG-объект; этот незавершённый проход не выдан за проверку. Точный обратный контроль сохранённой PCB выполнен независимо по десяти сериализованным окружностям и сравнению всех байтов. Сервер и программные зависимости не исправлялись.

## Происхождение проектных символов

Sirokko_Interface.kicad_sym содержит производные пяти символов KiCad libraries: Connector_Generic:Conn_01x02, Conn_01x03, Conn_01x04 и Device:C, Device:Fuse. Авторы исходной библиотеки — KiCad Library Contributors. Использована геометрия и распиновка из исходных кэшей проекта; изменения — проектные имена и адресные фильтры посадок. Перераспространяемая библиотечная подборка сохраняет CC-BY-SA 4.0 с исключением KiCad; оригинальный документ приложен как KICAD_SYMBOLS_LICENSE.md. Это не назначение новой лицензии всей конструкции.

## Незавершённое

Это устранение CAD-нарушений, не электрическая или тепловая квалификация. Прошивка, окончательное удалённое управление, сборочный чертёж, предельные токовые режимы, USB power path точного DevKit и гарантированные логические уровни HC-160A не закрыты. Контрольный вид также показывает вспомогательную надпись PANEL WINDOW; её назначение и связанную графику нужно адресно проверить перед окончательной сборочной документацией, а не считать отсутствие legacy уже доказанным. Питание, физическая запись прошивки, моторные и огневые испытания не выполнялись и не разрешены.
