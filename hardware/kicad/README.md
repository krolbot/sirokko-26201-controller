# KiCad — действующий проект Sirokko

Открывайте `Sirokko26201_control_motor_candidate.kicad_pro` в KiCad 10.0.8. В комплекте одна основная PCB, пять листов схемы, библиотеки и проектные модели. Вместо собственной панели используется покупной TFT 2.4″ + EC11.

- PCB SHA256: `3c414eb66da7ff7c6b44399a5515e97417703ccb50feea8ab9f17e66db17ab7f`.
- Root SCH SHA256: `10234cffe31a597494a45f9b3eb786bf3658f1df8872bafbda235fc0618970fd`.
- PRO SHA256: `11029d86464484cea63d73aa802bad95c1a6805aee11e841fc78322e9d2bc0d6`.
- Контур 305 × 170 мм; 73 посадки, 303 площадки, 753 сегмента, 172 перехода, 27 зон.
- DRC: 0 нарушений, 0 разрывов, без ignored checks. ERC: 0 зарегистрированных нарушений при четырёх сохранённых проектных ignored checks.
- Сверены 252 электрических назначения pin→net, 308 отверстий и 60 позиций установки. Сохранены UUID и геометрия всех 303 площадок; вне TFT_DC/CS неизменны 891 объект меди.

**Окончательные управляющие выводы TFT:** RES = GPIO6/J1.6; DC = GPIO41/J3.7; CS = GPIO42/J3.6. GPIO3 и входной GPIO46 не используются. GPIO9/10 остаются выборами MAX31856 и не заняты TFT. Старые описания назначения DC/CS на GPIO9/10 неверны.

J32 — IDC 2×6, SPI 3.3 В, кабель до 100 мм. Соединение с модулем не 1:1: [точная распиновка](../../docs/TFT24_INTERFACE_RU.md). [Текущие файлы изготовления и проверки](../../manufacturing/current/README_RU.md).

Неиспользуемые библиотечные символы не являются установленными компонентами. Стандартные и условные 3D-модели не доказывают полную геометрию сборки. `production_release=false`, `physical_tests=false`; прошивка не изменялась.
