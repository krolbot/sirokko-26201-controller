# KiCad — единственный актуальный проект

**DRAFT / NOT FOR ORDER / NO POWER / NO FIRE.**

Откройте `Sirokko26201_control_motor_candidate.kicad_pro` в KiCad 10.0.7. Корневая схема, PCB, все используемые дочерние листы, таблицы библиотек, проектные символы, посадочные места и локальные 3D-модели находятся в этом каталоге.

Точки входа:

- `Sirokko26201_control_motor_candidate.kicad_pro`;
- `Sirokko26201_control_motor_candidate.kicad_sch`;
- `Sirokko26201_control_motor_candidate.kicad_pcb`.

Имена отдельных подключённых листов содержат `DRAFT`, потому что электрическая и производственная приёмка не завершена. Эти файлы входят в действующую иерархию и не являются параллельными историческими проектами.

Проектные зависимости разрешаются через `${KIPRJMOD}` в `fp-lib-table` и `sym-lib-table`; стандартные модели — через `${KICAD10_3DMODEL_DIR}`.

Экран и его крепёж исключены новым требованием пользователя. Ранее выбранные Waveshare, Adafruit, DFR0650 и OLED 9001709304 больше не являются действующим выбором. Удаление оставшейся экранной геометрии с PCB ещё предстоит.

Прошивка отсутствует намеренно. Её новая реализация начинается после окончательной приёмки PCB и карты выводов.

Ревизионные копии, отчёты, рендеры и архивы рядом с проектом не хранятся. Для восстановления прежних состояний используется история Git.

## Актуальное управление: только удалённо через ESP32

Экран, кнопка Start/Stop и энкодер исключены. Их схема и отдельная обвязка удалены, освобождённые выводы ESP отмечены NC. Подробности: [REMOTE_ONLY_REQUIREMENTS_RU.md](REMOTE_ONLY_REQUIREMENTS_RU.md). PCB ещё не синхронизирована с этой схемой; прежний результат DRC ниже относится к историческому HC160-снимку, а не к новому удалённому варианту. Прошивка удалённого управления не реализована.

## Внешний моторный модуль

Встроенный силовой ШИМ удалён из схемы и платы. HC-160A-S2 подключается только управляющим жгутом к J29: `1=A1/FAN_REQUEST`, `2=A2/GND`, `3=PA/SPEED_CMD`, `4=G/GND`. Модуль не крепится к PCB; питание двигателя проходит вне неё. Подробности и ограничения: [HC160_INTERFACE_RU.md](HC160_INTERFACE_RU.md).

Для текущей замены: ERC=0, обрывы=0, PCB↔SCH=0, DRC error=0; сохранены 54 прежних предупреждения (код DRC 5). Замена проверена в CAD, общий производственный выпуск не разрешён.
