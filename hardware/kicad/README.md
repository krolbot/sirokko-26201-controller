# KiCad — действующий проект Sirokko

Открывайте `Sirokko26201_control_motor_candidate.kicad_pro` в KiCad 10.0.8. В комплекте одна основная PCB, пять листов схемы, библиотеки и проектные модели. Вместо собственной панели используется покупной TFT 2.4″ + EC11.

- PCB SHA256: `0ed3728e0cd427c01e9509a6aff25a2870087f775708396bfdd9fabb0b346e82`.
- Root SCH SHA256: `0b85bf2f4921b25a1c3126348eb176a88c7e3b29ca474c2d7229c4367e0a5cf5`.
- PRO SHA256: `11029d86464484cea63d73aa802bad95c1a6805aee11e841fc78322e9d2bc0d6`.
- Контур 281 × 170 мм; 73 посадки, 303 площадки, 663 сегмента, 115 переходов, 25 зон.
- DRC: 0 нарушений, 0 разрывов, без ignored checks. ERC: 0 зарегистрированных нарушений при четырёх сохранённых проектных ignored checks.
- Сверены 252 электрических назначения pin→net, 251 отверстие и 60 позиций установки. Сохранены UUID, сети и локальная геометрия всех 303 площадок; В v6 J32 и правый блок перекомпонованы; в v7 переразведены цепи и перенесены R7/R8 для свободного доступа к J29. 178 → 147 → 115 переходов; глобальный минимум не доказан.

**Окончательные управляющие выводы TFT:** RES = GPIO6/J1.6; DC = GPIO41/J3.7; CS = GPIO42/J3.6. Загрузочные GPIO3/46 не используются. GPIO9/10 остаются выборами MAX31856 и не заняты TFT. Старые описания назначения DC/CS на GPIO9/10 неверны.

J32 — IDC 2×6, SPI 3.3 В, кабель до 100 мм. Соединение с модулем не 1:1: [точная распиновка](../../docs/TFT24_INTERFACE_RU.md). [Текущие файлы изготовления и проверки](../../manufacturing/current/README_RU.md).

Неиспользуемые библиотечные символы не являются установленными компонентами. Стандартные и условные 3D-модели не доказывают полную геометрию сборки. `production_release=false`, `physical_tests=false`; KEY0 подключена аппаратно. Её программный обработчик не входит в этот выпуск; прошивка и локальный интерфейс требуют согласования.
