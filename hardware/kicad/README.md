# KiCad — единственный актуальный проект

**DRAFT / NOT FOR ORDER / NO POWER / NO FLASH / NO FIRE.**

Откройте `Sirokko26201_control_motor_candidate.kicad_pro` в KiCad 10.0.7. Корневая схема, PCB, все используемые дочерние листы, таблицы библиотек, проектные символы, посадочные места и локальные 3D-модели находятся в этом каталоге.

Точки входа:

- `Sirokko26201_control_motor_candidate.kicad_pro`;
- `Sirokko26201_control_motor_candidate.kicad_sch`;
- `Sirokko26201_control_motor_candidate.kicad_pcb`.

Имена отдельных подключённых листов содержат `DRAFT`, потому что электрическая и производственная приёмка не завершена. Эти файлы входят в действующую иерархию и не являются параллельными историческими проектами.

Проектные зависимости разрешаются через `${KIPRJMOD}` в `fp-lib-table` и `sym-lib-table`; стандартные модели — через `${KICAD10_3DMODEL_DIR}`.

Экран и его крепёж исключены новым требованием пользователя. Ранее выбранные Waveshare, Adafruit, DFR0650 и OLED 9001709304 больше не являются действующим выбором. Их посадочные места, отдельная медь и экранные крепления удалены из основной PCB.

Прошивка отсутствует намеренно. Её новая реализация начинается после окончательной приёмки PCB и карты выводов. Проверенная текущая таблица контактов, релейная логика и пределы питания: [ELECTRICAL_INTERFACE_RU.md](ELECTRICAL_INTERFACE_RU.md). Для J29 артикул Phoenix Contact 1715747 теперь внесён в схему и PCB; заводские шаг и сверления сопоставлены с действующей посадкой. Создана штатная CSV-спецификация с MPN всех 79 схемных экземпляров, пока DRAFT / NOT FOR ORDER, не окончательная закупочная ведомость.

Ревизионные копии, отчёты, рендеры и архивы рядом с проектом не хранятся. Для восстановления прежних состояний используется история Git.

## Актуальное управление: только удалённо через ESP32

Экран, кнопка Start/Stop и энкодер исключены. Их схема и отдельная обвязка удалены, освобождённые выводы ESP отмечены NC. Подробности: [REMOTE_ONLY_REQUIREMENTS_RU.md](REMOTE_ONLY_REQUIREMENTS_RU.md). Основная PCB синхронизирована со схемой; её свежие ERC/DRC и проверка сохранности соединений описаны в [PCB_REVIEW_RU.md](PCB_REVIEW_RU.md). Прошивка удалённого управления не реализована.

## Внешний моторный модуль

Встроенный силовой ШИМ удалён из схемы и платы. HC-160A-S2 подключается только управляющим жгутом к J29: `1=A1/FAN_REQUEST`, `2=A2/GND`, `3=PA/SPEED_CMD`, `4=G/GND`. Модуль не крепится к PCB; питание двигателя проходит вне неё. Подробности и ограничения: [HC160_INTERFACE_RU.md](HC160_INTERFACE_RU.md).

Для текущей удалённой ревизии: ERC=0; DRC=0 ошибок и 0 предупреждений, обрывы=0, PCB↔SCH=0; код завершения обеих проверок 0. Сохранены 2703 прежние пары физически соединённых площадок. Плата остаётся двухслойной: 897 сегментов, 261 переход. Это CAD-проверка; электрическая и тепловая приёмка изделия, прошивка и производственный выпуск не завершены.
