# Sirokko 262.01 — контроллер автоматики

> **DRAFT / NOT FOR ORDER / NO POWER / NO FLASH / NO FIRE.** Плата не закончена, не прошла производственную и физическую приёмку и не предназначена для заказа, подачи питания, прошивки или работы с горелкой.

В рабочем дереве оставлен один актуальный полный проект KiCad:

- проект: [`hardware/kicad/Sirokko26201_control_motor_candidate.kicad_pro`](hardware/kicad/Sirokko26201_control_motor_candidate.kicad_pro);
- схема: [`hardware/kicad/Sirokko26201_control_motor_candidate.kicad_sch`](hardware/kicad/Sirokko26201_control_motor_candidate.kicad_sch);
- плата: [`hardware/kicad/Sirokko26201_control_motor_candidate.kicad_pcb`](hardware/kicad/Sirokko26201_control_motor_candidate.kicad_pcb);
- SHA-256 текущей PCB: `46c5a025f705e98b6a2d853b51888a136c769dc52878588313bf9c5c6169381f`.

Текущая PCB содержит 144 посадочных места, 1537 сегментов, 447 переходных отверстий и 35 зон. Относительно предыдущего опубликованного WIP добавлены шесть сегментов F.Cu `/GND` без новых переходных отверстий; прежняя медь не удалена и не изменена. Полный набор пар площадок вырос с 3988 до 5684: потерянных связей нет, добавлены 1696 связей `/GND`. Четыре сегмента присоединили R86.2 и R87.2 к группе U11/C21/C22; ещё два объединили группу J1/J3 из 24 площадок с проверенной основной GND-группой из 70 площадок в одну группу из 94 площадок. Это ограниченная проверка WIP-маршрутов, а не приёмка всей земли. Разводка ещё не закончена. Отдельная кнопка RESET, J24, R702 и цепь `RESET_RELEASED` удалены без замены внешней колодкой, перемычкой или скрытой кнопкой. U6.4 постоянно подключён к `+3V3`; watchdog, аппаратная защёлка, автоматический сброс и требование нового `ARM_PULSE` сохранены.

Последняя нативная проверка KiCad 10.0.7 зафиксировала 61 предупреждение DRC и 21 незамкнутое соединение; проблем соответствия схемы плате нет. ERC сообщает об одном предупреждении `isolated_pin_label` для `EN_CHIP_PU`. Это состояние незавершённой платы, а не допуск к изготовлению.

Отозванная условная модель крепежа голого TFT на стойках M2×12 удалена. Официальная номинальная STEP-модель Waveshare 18366 сохранена, но резьба, высота штатных опор, сопрягаемые детали и полный высотный размер не приняты.

Прошивки в рабочем дереве нет. Прежняя стендовая реализация была отвергнута как основа конечного изделия и доступна только через историю Git. При будущей разработке после приёмки PCB старые функции ручного RESET не восстанавливать; взведение выполняет `ARM_PULSE` только при допустимом пуске. Драйвер ILI9341 отсутствует.
