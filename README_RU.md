# Sirokko 262.01 — контроллер автоматики

> **DRAFT / NOT FOR ORDER / NO POWER / NO FLASH / NO FIRE.** Плата не закончена, не прошла производственную и физическую приёмку и не предназначена для заказа, подачи питания, прошивки или работы с горелкой.

В рабочем дереве оставлен один актуальный полный проект KiCad:

- проект: [`hardware/kicad/Sirokko26201_control_motor_candidate.kicad_pro`](hardware/kicad/Sirokko26201_control_motor_candidate.kicad_pro);
- схема: [`hardware/kicad/Sirokko26201_control_motor_candidate.kicad_sch`](hardware/kicad/Sirokko26201_control_motor_candidate.kicad_sch);
- плата: [`hardware/kicad/Sirokko26201_control_motor_candidate.kicad_pcb`](hardware/kicad/Sirokko26201_control_motor_candidate.kicad_pcb);
- SHA-256 текущей PCB: `351c76ea07d4622820c5444107610fd71b36d6842d54ab2a8f3dfad61c8d3b6f`.

Текущая PCB содержит 144 посадочных места, 1536 сегментов, 447 переходных отверстий и 35 зон. Относительно непосредственно предшествующего опубликованного WIP удалён ровно один изолированный сегмент F.Cu `/+3V3`: UUID `248bebb3-e137-4f67-b1e3-b978ff56dd51`, `(286.1375,24.05)→(287.2,24.05)`, ширина 0,25 мм. Остальная медь не изменилась, полный набор из 5684 пар площадок совпадает. Шесть проверенных сегментов F.Cu `/GND` сохранены: они присоединяют R86.2 и R87.2 к U11/C21/C22 и объединяют группу J1/J3 из 24 площадок с проверенной основной GND-группой из 70 площадок в одну группу из 94 площадок. Это ограниченная проверка WIP, а не приёмка всей платы. Разводка ещё не закончена. Отдельная кнопка RESET, J24, R702 и цепь `RESET_RELEASED` удалены без замены внешней колодкой, перемычкой или скрытой кнопкой. U6.4 постоянно подключён к `+3V3`; watchdog, аппаратная защёлка, автоматический сброс и требование нового `ARM_PULSE` сохранены.

Последняя нативная проверка KiCad 10.0.7 зафиксировала 60 предупреждений DRC и 20 незамкнутых соединений; проблем соответствия схемы плате нет. ERC сообщает об одном предупреждении `isolated_pin_label` для `EN_CHIP_PU`. Это состояние незавершённой платы, а не допуск к изготовлению.

Отозванная условная модель крепежа голого TFT на стойках M2×12 удалена. Официальная номинальная STEP-модель Waveshare 18366 сохранена, но резьба, высота штатных опор, сопрягаемые детали и полный высотный размер не приняты.

Прошивки в рабочем дереве нет. Прежняя стендовая реализация была отвергнута как основа конечного изделия и доступна только через историю Git. При будущей разработке после приёмки PCB старые функции ручного RESET не восстанавливать; взведение выполняет `ARM_PULSE` только при допустимом пуске. Драйвер ILI9341 отсутствует.
