> **DRAFT / NOT FOR ORDER / NO POWER / NO FLASH / NO FIRE.** Плата не закончена, не имеет производственного допуска и не прошла физическую приёмку. Её нельзя заказывать, включать, прошивать или подключать к горелке.

В рабочем дереве оставлен один актуальный проект KiCad:

- проект: [`hardware/kicad/Sirokko26201_control_motor_candidate.kicad_pro`](hardware/kicad/Sirokko26201_control_motor_candidate.kicad_pro);
- схема: [`hardware/kicad/Sirokko26201_control_motor_candidate.kicad_sch`](hardware/kicad/Sirokko26201_control_motor_candidate.kicad_sch);
- плата: [`hardware/kicad/Sirokko26201_control_motor_candidate.kicad_pcb`](hardware/kicad/Sirokko26201_control_motor_candidate.kicad_pcb);
- интерфейс HC-160A-S2: [`hardware/kicad/HC160_INTERFACE_RU.md`](hardware/kicad/HC160_INTERFACE_RU.md);
- SHA-256 текущей PCB: `b11c63de29efd64ce23d33bcd5e74f7ddecd919ec385467222ebf0c1102e6cf3`.

PCB содержит 117 посадочных мест, 439 физических площадок, 1357 сегментов и 419 переходных отверстий. Прежний встроенный силовой мост двигателя и 28 его компонентов удалены. HC-160A-S2 — отдельный внешний модуль без крепления на этой PCB; оба провода двигателя и силовое питание идут непосредственно к модулю. Колодка Sirokko J29 передаёт только управление: `1=A1/FAN_REQUEST`, `2=A2/GND`, `3=PA/SPEED_CMD`, `4=G/GND`. Выход `+5V OUT` модуля не используется. `J1.11/GPIO18` — NC.

Проверка парного проекта в KiCad 10.0.7 без записи исходников успешно выгрузила список цепей и зафиксировала 0 нарушений ERC, 0 несоединённых элементов, 0 расхождений PCB↔SCH и 0 нарушений DRC уровня ошибки. Общая DRC всё ещё завершается кодом 5 из-за 51 предупреждения: 46 `track_dangling` и 5 `copper_sliver`. Это не чистое прохождение DRC и не производственная приёмка.

Согласованной с этим аппаратным контрактом прошивки нет. Прежнюю прошивку, которая управляет GPIO18 или предполагает встроенный моторный каскад, прошивать нельзя. Согласование прошивки начинается только после приёмки PCB и окончательной карты выводов.

Ранее рассматривавшийся Waveshare 18366 больше не выбран. Новый экран ещё подбирается; 12219 — только кандидат, окончательный способ крепления не подтверждён. Существующая геометрия экрана в этом WIP-снимке не является производственным решением.
