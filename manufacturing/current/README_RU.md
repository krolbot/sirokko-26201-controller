- Root ERC: 0 нарушений.
- Native DRC после перезаливки: 0 нарушений, 0 несоединений; отчёт — [`checks/native-drc.json`](checks/native-drc.json).
- [`prefab-gate.json`](prefab-gate.json): `passed=true`, блокирующих замечаний нет, проверка соответствия схеме запущена и не отменена, `ignored_checks=[]`, `excluded=0`.
- Структурное сравнение подтвердило неизменность всех прежних 70 посадочных мест, 633 сегментов, 145 переходов и прежних площадок. Добавлены только R108/C109, шесть сегментов и два перехода.
- Лицевая/обратная стороны и 3D-виды пересобраны и осмотрены; явной обрезки, выхода компонентов за контур или компонентов на B.Cu не обнаружено.

Неблокирующие предупреждения gate о проектных библиотеках и неизвестном токе срабатывания F1 сохранены в отчёте. Прохождение gate не является разрешением заказа или полной аппаратной приёмкой.

Manifest описывает staged-копию, которую Pre-fab Gate проверил и упаковал, поэтому его внутренний SHA платы не подменяет канонический SHA исходника выше. Исходный файл gate не изменял: `source_modified=false`.

## Сборка и подключения

Перед монтажом читать [актуальную карту внешних подключений](../../docs/research/CONTROL_CONNECTIONS_CURRENT_RU.md) и [изображение контактов](../../docs/research/CONTROL_CONNECTIONS_CURRENT.png). USB используется только для прошивки вынутого DevKit. Термопары подключаются к клеммам самих MAX31856. Высота стоек и винты модулей этим комплектом не назначены.

Требования и оставшиеся ограничения: [`FABRICATION_REQUIREMENTS_RU.md`](FABRICATION_REQUIREMENTS_RU.md). Текущий единый Excellon не заменяет требуемую перед реальным заказом проверку политики PTH/NPTH конкретного изготовителя.

Пуск, DC-bias, горячая SOA, импульсная координация, электрическая/тепловая/механическая приёмка и физическая работа отопителя не подтверждены. Заказ, питание, прошивка и огневые испытания не разрешены.
