# Sirokko — предварительные сборочные виды

**DRAFT / NOT FOR ORDER / NO POWER / NO FLASH / NO FIRE.**

- `ASSEMBLY_FRONT_DRAFT.pdf` — вид сверху на несущую PCB.
- `ASSEMBLY_BACK_DRAFT.pdf` — зеркальный вид снизу. Зеркальность относится только к направлению просмотра обратной стороны и не означает зеркальную установку ESP32 DevKit или других компонентов.
- PDF выполнены с автоматическим масштабированием страницы. Это не размерный шаблон и не печать 1:1.
- Точные MPN задаёт BOM. На видах показаны обозначения Ref и полярность; скрытие Value при экспорте не меняет CAD или BOM.

Действующий J29 — только управляющий разъём `A1 / A2 / PA / G`; `GPIO18` остаётся NC. Экрана, Start/Stop, энкодера и отдельной RESET нет. `MCU_PERMIT` управляет только K3 и не является общим отключением свечи.

Это предварительные двумерные сборочные виды, а не выпущенный сборочный чертёж, 3D-проверка или приёмка физической сборки. Питание, запись прошивки, подключение двигателя и огневые испытания запрещены.
