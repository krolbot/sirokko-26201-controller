## Ревизия

Экспорт пересобран штатным KiCad CLI 10.0.7 из двухрелейной PCB. K3 и R703 удалены; K2.87 соединён напрямую с J28.1 дорожкой шириной 4 мм без переходов. Это геометрический факт, не токовый или тепловой допуск. Плата двухслойная; однослойная версия не заявляется.

## Состав

- `gerber/`: девять Gerber X2 — F.Cu/B.Cu, F.Mask/B.Mask, F.Paste/B.Paste, F.SilkS/B.SilkS, Edge.Cuts; job-файл с параметрами исходной CAD и штатный отчёт сверления.
- Два Excellon-файла: раздельные PTH и NPTH, миллиметры, абсолютное начало, десятичные координаты, без зеркалирования. 346 металлизированных и 13 неметаллизированных отверстий по штатному отчёту.
- `placement/POSITIONS_ALL_DRAFT.csv`: 77 схемных позиций для общего сборочного размещения; это НЕ список исключительно для SMT-автомата.
- `placement/POSITIONS_SMD_DRAFT.csv`: 56 SMD-позиций верхней стороны, без DNP и посадок с отверстиями. Применён штатный фильтр KiCad, отсутствие просверленных площадок в этих 56 посадках проверено native.
- `bom/`: исходный схемный BOM, отдельная предварительная закупочная группировка и примечания. Реле/колодки и предохранитель/держатель в закупочной таблице разделены, но в placement представлены схемными сборочными позициями. Съёмные реле не паять вместо колодок.
- `check/drc.json`: свежий полный DRC с all-track-errors, schematic-parity, refill-zones, severity-all и exit-code-violations: exit 0, violations 0, unconnected_items 0, schematic_parity 0.
- `assembly/`: два предварительных сборочных PDF и краткие примечания по направлению просмотра и ограничениям.
- `SHA256SUMS`: контрольные суммы файлов, кроме самого манифеста.

## Координаты, ориентация и сверление

Gerber и Excellon: единицы mm, абсолютное начало исходной PCB, без ребазирования и зеркалирования. CSV placement штатного KiCad: PosX = native X; PosY = минус native Y; Rot в градусах; Side top/bottom. Отрицательные PosY намеренны, не менять знак вручную. Для CSV не применялись --bottom-negate-x и --use-drill-file-origin. Все 77 координат/углов/сторон построчно сверены с native PCB; J1/J3 находятся снизу. Угол библиотеки KiCad не является уже согласованной ориентацией в библиотеке сборочного автомата завода: проверка pin 1 и полярности при подготовке монтажа обязательна.

Исходная толщина PCB в CAD 1,6 мм; это не согласованная спецификация материала, допуска толщины, массы меди или стека изготовителя. Файл .gbrjob содержит настройки CAD, а не подтверждённые условия заказа. Минимальная ширина сегмента в PCB 0,2 мм; это наблюдение, не общий токовый допуск и не полная проверка технологии. Отверстия PTH задают проектные размеры, а допуски готовых отверстий и металлизацию необходимо согласовать с изготовителем.

1. Canonical ERC и DRC выполнены для этой двухрелейной ревизии; обе команды завершились кодом 0. DRC: нарушений 0, обрывов 0, расхождений PCB↔SCH 0, `ignored_checks=[]`. ERC: нарушений 0, четыре стандартных исключения перечислены в `check/erc.json`.
2. Проверено совпадение наборов references исходного BOM и общего placement, уникальность позиций, native координаты, углы, стороны и отсутствие THT в SMT-подмножестве.
3. Девять Gerber, два Excellon, placement и сборочные PDF заново экспортированы из PCB `1905414e…d1517`; после исключения временных дат геометрия CAM совпала с предыдущим комплектом, а в placement изменено только значение C104.
4. Последние `ASSEMBLY_FRONT_DRAFT.pdf` и `ASSEMBLY_BACK_DRAFT.pdf` экспортированы штатным KiCad CLI и визуально проверены до публикации. Это предварительные виды, не новый полный CAM-просмотр и не производственная приёмка.
5. Контрольные суммы после передачи с CAD-сервера сверены с источниками. Полный ZIP пересобран из этого каталога и не добавляется в Git.

При native readback pcbnew вывел три диагностических assert-сообщения PROPERTY_ENUM о пустом списке enum, затем вернул полные данные и exit 0. Подтверждены все проверяемые значения; эти сообщения не выданы за ошибки DRC и не скрыты. Сервер и приложение не исправлялись.
