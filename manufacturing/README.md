# Изготовление платы

[Gerber REV C](pcb/gerbers.zip) — комплект для изготовления платы: медь, маска, паста, шелкография, контур и сверловка PTH/NPTH.

| Параметр | Значение |
|---|---|
| Материал | FR-4 |
| Размер | 100 × 100 мм |
| Слои | 2 |
| Толщина | 1,6 мм |
| Медь | 35 мкм / 1 oz |
| Маска | С обеих сторон |
| Переходы | Сквозные, без заполнения |
| Покрытие | Бессвинцовое HASL или ENIG |

Крепёжные отверстия: четыре Ø3,2 мм под M3 и четыре Ø2,2 мм под M2. Всего 141 металлизированное отверстие, включая 51 переход, и восемь неметаллизированных.

## CAM

[Sirokko.cam](pcb/Sirokko.cam) — настройки экспорта Fusion. В производственном архиве сверловка разделена на PTH и NPTH; крепёжные отверстия — в NPTH. Файл контура содержит только внешнюю границу платы.

[SHA256SUMS](SHA256SUMS) содержит контрольные суммы файлов; пути указаны от корня репозитория.
