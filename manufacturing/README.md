# Заказать плату и монтаж

## Только изготовление PCB

**Gerber и сборочный PDF в этом каталоге относятся к предыдущей ревизии.** Для заказа текущей платы нужен новый CAM-экспорт из [Sirokko.brd](../hardware/Sirokko.brd). CSV спецификации и координат обновлены.

| Параметр | Значение |
|---|---|
| Материал | FR-4 |
| Размер | **100 × 100 мм** |
| Слои | 2 |
| Толщина | 1,6 мм |
| Медь | 35 мкм / 1 oz |
| Маска | С обеих сторон |
| Переходы | Обычные сквозные, без заполнения |
| Покрытие | Бессвинцовое; ENIG не обязателен |

В архиве нужны Gerber обеих сторон, контур и Excellon-сверловка с разделением металлизированных и неметаллизированных отверстий. Четыре крепления платы — под M3, четыре крепления MAX31856 — под M2. Корпусные выводы U101 используют круглые металлизированные отверстия 3,1 мм; фрезерованных пазов для них нет.

## Заказ монтажа

Для монтажа используйте файлы из **[assembly](assembly)**, соответствующие той же версии платы:

| Работа | BOM | Координаты установки |
|---|---|---|
| Только SMD | [bom-smt.csv](assembly/bom-smt.csv) | [positions-smt.csv](assembly/positions-smt.csv) |
| Вся плата, включая THT | [bom.csv](assembly/bom.csv) | [positions.csv](assembly/positions.csv) |

Для монтажа требуется новый сборочный чертёж. [assembly.pdf](assembly/assembly.pdf) показывает предыдущую ревизию. Возможность монтажа выводного U101 и разъёмов согласуйте с изготовителем. Артикулы указаны как MPN, не как коды каталога монтажника.

F1 — непосредственно SMD-предохранитель, отдельного держателя нет. Внешние реле не устанавливаются на PCB и не входят в её монтажные координаты. DevKit и MAX31856 вставляются в соответствующие колодки после монтажа. Полный комплект — в [ведомости компонентов](../hardware/BOM.md); подключения — в [инструкции сборки](../docs/assembly.md).

Координаты установки приведены в миллиметрах по текущему экспорту Fusion/EAGLE. При подготовке монтажа сверяйте ориентацию, сторону и первый вывод со сборочным видом; прежние координаты KiCad к этой плате не относятся.
