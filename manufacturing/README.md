# Изготовление платы

[Gerber и сверловка](pcb/gerbers.zip) — архив для заказа платы.

| Параметр | Значение |
|---|---|
| Материал | FR-4 |
| Размер | 90 × 75 мм |
| Слои | 2 |
| Толщина | 1,6 мм |
| Медь | 35 мкм / 1 oz |
| Маска | С обеих сторон |
| Переходы | Сквозные, без заполнения |
| Покрытие | Бессвинцовое HASL или ENIG |

Крепёжные отверстия неметаллизированные: четыре Ø3,2 мм под M3 и четыре Ø2,2 мм под M2.

## Монтаж

| Состав заказа | Ведомость | Координаты |
|---|---|---|
| SMD-компоненты | [bom-smt.csv](assembly/bom-smt.csv) | [positions-smt.csv](assembly/positions-smt.csv) |
| Все компоненты платы | [bom.csv](../hardware/bom.csv) | [positions.csv](assembly/positions.csv) |

[Сборочный чертёж](assembly/assembly.pdf) — вид сверху. Координаты даны в миллиметрах от левого нижнего угла платы. U101 и разъёмы имеют выводной монтаж; ESP32 и MAX31856 устанавливаются в колодки.

Центральная площадка U100 припаивается к плате; в трафарете для неё предусмотрены четыре окна. Тепловые переходы расположены рядом с площадкой.
