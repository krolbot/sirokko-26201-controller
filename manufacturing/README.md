# Заказать плату и монтаж

## Только изготовление PCB

[gerbers.zip](pcb/gerbers.zip), сборочный PDF и CSV выгружены из текущей платы Fusion. Настройки экспорта сохранены в [Sirokko.cam](pcb/Sirokko.cam).

| Параметр | Значение |
|---|---|
| Материал | FR-4 |
| Размер | **100 × 100 мм** |
| Слои | 2 |
| Толщина | 1,6 мм |
| Медь | 35 мкм / 1 oz |
| Маска | С обеих сторон |
| Переходы | Обычные сквозные, без заполнения |
| Покрытие | Бессвинцовое; ENIG не обязателен |

В архиве находятся Gerber обеих сторон, контур и Excellon-сверловка с разделением металлизированных и неметаллизированных отверстий. Четыре крепления платы — под M3, четыре крепления MAX31856 — под M2. U101 имеет три металлизированных отверстия диаметром 1 мм. Всего 149 металлизированных отверстий, включая 59 переходов, и 8 неметаллизированных крепёжных.

## Заказ монтажа

Для монтажа используйте файлы из **[assembly](assembly)**, соответствующие той же версии платы:

| Работа | BOM | Координаты установки |
|---|---|---|
| Только SMD | [bom-smt.csv](assembly/bom-smt.csv) | [positions-smt.csv](assembly/positions-smt.csv) |
| Вся плата, включая THT | [bom.csv](assembly/bom.csv) | [positions.csv](assembly/positions.csv) |

[assembly.pdf](assembly/assembly.pdf) — текущий сборочный чертёж, вид сверху. Возможность монтажа выводного U101 и разъёмов согласуйте с изготовителем. Артикулы указаны как MPN, не как коды каталога монтажника.

F1 — непосредственно SMD-предохранитель, отдельного держателя нет. Внешние реле не устанавливаются на PCB и не входят в её монтажные координаты. DevKit и MAX31856 вставляются в соответствующие колодки после монтажа. Полный комплект — в [ведомости компонентов](../hardware/BOM.md); подключения — в [инструкции сборки](../docs/assembly.md).

Координаты установки приведены в миллиметрах по текущему экспорту Fusion/EAGLE. При подготовке монтажа сверяйте ориентацию, сторону и первый вывод со сборочным видом; прежние координаты KiCad к этой плате не относятся.

CAM Fusion выдаёт общую сверловку. В архиве она разделена по инструментам на PTH и NPTH без изменения координат. Круги крепёжных отверстий исключены из слоя внешнего контура, поскольку они уже заданы в NPTH. Контур — квадрат 100 × 100 мм; начало координат — левый нижний угол.

Для заказа отправляйте только `pcb/gerbers.zip`. Каталог `pcb/native-cam` содержит исходную выгрузку Fusion для проверки преобразования сверловки и контура; отдельно изготовителю его отправлять не нужно. Контрольные суммы исходников и производственного комплекта — в [SHA256SUMS](SHA256SUMS), пути отсчитываются от корня репозитория.
