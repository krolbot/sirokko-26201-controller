# Заказать плату и монтаж

## Только изготовление PCB

Загрузите **[pcb/gerbers.zip](pcb/gerbers.zip)** в JLCPCB или передайте выбранному изготовителю.

| Параметр | Значение |
|---|---|
| Материал | FR-4 |
| Размер | 281 × 170 мм |
| Слои | 2 |
| Толщина | 1,6 мм |
| Медь | 35 мкм / 1 oz |
| Маска | С обеих сторон |
| Переходы | Обычные сквозные, без заполнения |
| Покрытие | Бессвинцовое; ENIG не обязателен |

В ZIP — Gerber, контур и отдельные Excellon-файлы металлизированных и неметаллизированных отверстий. Нижние паста и шелкография пустые.

## Заказ монтажа

Для монтажа нужны файлы из **[assembly](assembly)**:

| Работа | BOM | Координаты установки |
|---|---|---|
| Только SMD | [bom-smt.csv](assembly/bom-smt.csv) | [positions-smt.csv](assembly/positions-smt.csv) |
| Вся плата, включая THT | [bom.csv](assembly/bom.csv) | [positions.csv](assembly/positions.csv) |

Приложите **[assembly.pdf](assembly/assembly.pdf)**. Возможность монтажа выводных компонентов согласуйте с изготовителем. Артикулы указаны как MPN, не как коды LCSC: каталог монтажника нужно сопоставить при заказе.

В этих BOM F1 — держатель предохранителя, K1/K2 — колодки реле. Полный комплект для закупки находится в [ведомости компонентов](../hardware/BOM.md), а порядок сборки — в [инструкции сборки](../docs/assembly.md).

Координаты в миллиметрах; `Mid Y` — отрицательная координата Y KiCad, углы — градусы KiCad. После импорта сверяйте ориентацию и первый вывод по сборочному виду. PDF выполнен в обзорном масштабе.
