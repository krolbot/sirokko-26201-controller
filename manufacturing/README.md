# Производственный комплект

В DRAFT-02 производственного комплекта нет. Незавершённый PCB-файл находится в `../hardware/kicad/`, но Gerber, Excellon, BOM и CPL не выпущены; этот файл не является производственным артефактом.

Добавлять сюда файлы можно только после проверки схемы, трассировки, DRC, номиналов силовой части и соответствия конкретным закупаемым компонентам.
