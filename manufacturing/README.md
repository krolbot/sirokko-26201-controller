# Изготовление платы

Текущая плата — **REV C**. Для заказа PCB нужен архив [gerbers.zip](pcb/gerbers.zip): медь, маска, паста, шелкография, контур и сверловка PTH/NPTH.

| Параметр | Значение |
|---|---|
| Материал | FR-4 |
| Размер | 100 × 100 мм |
| Слои | 2 |
| Толщина | 1,6 мм |
| Медь | 35 мкм / 1 oz |
| Маска | С обеих сторон |
| Переходы | Сквозные, без заполнения |
| Покрытие | Бессвинцовое HASL или ENIG |

Крепёжные отверстия: четыре Ø3,2 мм под M3 и четыре Ø2,2 мм под M2. Всего 141 металлизированное отверстие, включая 51 переход, и восемь неметаллизированных.

## Монтаж

| Состав заказа | Ведомость | Координаты |
|---|---|---|
| SMD-компоненты | [bom-smt.csv](assembly/bom-smt.csv) | [positions-smt.csv](assembly/positions-smt.csv) |
| Все компоненты платы | [bom.csv](../hardware/bom.csv) | [positions.csv](assembly/positions.csv) |

[Сборочный чертёж](assembly/assembly.pdf) — вид сверху. Координаты даны в миллиметрах от левого нижнего угла платы. Ведомости содержат артикулы производителей. Преобразователь U101 и разъёмы имеют выводной монтаж; ESP32 и модули термопар устанавливаются в колодки.

## CAM

[Sirokko.cam](pcb/Sirokko.cam) — настройки экспорта Fusion. Для заказного архива общая сверловка разделяется на PTH и NPTH; крепёжные отверстия входят только в NPTH, внешний контур содержит границу платы.

[SHA256SUMS](SHA256SUMS) содержит контрольные суммы файлов; пути указаны от корня репозитория.
