# Производственный комплект

В текущем WIP-снимке производственного комплекта нет. Восстановленный незавершённый PCB-файл находится в `../hardware/kicad/`, но Gerber, Excellon, закупочная BOM и CPL не выпущены; этот файл не является производственным артефактом. Проверки и ограничения: `../hardware/WIP_CHECKPOINT.md`.

Добавлять сюда файлы можно только после проверки схемы, трассировки, DRC, номиналов силовой части и соответствия конкретным закупаемым компонентам.
