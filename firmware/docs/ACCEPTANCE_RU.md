# Программная приёмка Sirokko 262.01 — 1.0.0-dev1

Дата: 2026-11-06. Цель: ESP32-S3, ESP-IDF 5.2.3, плата и распиновка без изменений.
Статус: локальный программный комплект; не огневая квалификация, не физическая загрузка и не опубликованный Git-коммит.

## Реально выполненные проверки

- `python3 firmware/tests/run_host_tests.py`: exit 0; девять наборов ядра/панели/OTA activation плюс полный web/OTA suite.
- Температурные декодеры: 352 MAX31856-вектора и 31 DS18B20-вектор; исправность/свежесть данных, границы времени, STOP и порядок выходов.
- PI/ручной режим, ограничители команды, переходы, таймер выключения/отмена/граница истечения и одноразовый отложенный пуск.
- Полный автоматический калибровочный цикл на синтетическом процессе, противоположные температурные отклики, охлаждение до сохранения, отказ записи и отрицательные сигналы/STOP.
- NVS codec: 448 одиночных битовых повреждений отклонены; версия/размер/тип проверяются отдельно от смысловой валидации.
- KEY0, энкодер, модель меню, кириллица и различение регистра пароля; синтетический TFT-рендер осмотрен.
- Реальные production HTTP handlers с тестовым ESP-транспортом: авторизация, grant/replay, STOP, ограничения приёма, подпись и неправильный целевой чип.
- Независимое ревью нашло NUL-префикс JSON и потерю maintenance после `esp_ota_end`. Три отрицательные проверки этих путей до исправления падали; после исправления проходят. JSON передаётся с фактической длиной; активация принадлежит control task с отзывным epoch.
- Браузерный SHA-256 проверен с Web Crypto и без него: HTTP AP использует встроенный MIT js-sha256 0.11.1. Сравнение с Node crypto включает граничные длины и бинарный буфер 1 MiB.
- ASan/UBSan: интеграция калибровки и admission/epoch OTA — exit 0.
- Полная целевая компиляция/линковка и повторная сборка после исправлений — exit 0. Образ ESP32-S3 создан, помещается в OTA-раздел.
- `esptool 4.7.0 image_info`: checksum и validation hash действительны. Бинарная таблица разделов разобрана и проверена штатным ESP-IDF инструментом.
- Реальный поставляемый `.sota` проверен production `ota_verify.cpp` с соответствующим открытым ключом; исходный image, подпись, размер, проект и target приняты; изменённые/усечённые копии отвергнуты.
- `git diff --check`: exit 0. Все 124 файла защищённого аппаратного/производственного baseline совпали.

## Образ приложения

Размер: 1006640 байт.
SHA-256: `ae5468ca3d509d5251130e561e089c8b969859c6f69520930e489b03e5f60dd8`.

SDK-контейнер: `espressif/idf@sha256:9cd723f013e1a8b22aeed61c02e3248bb11e8f2e2ae333cee08a18b9e36c1380`.
Логи host/target/signature и SHA-256 манифест включены в архив. Исходники — точный рабочий снимок, а не содержимое последнего Git HEAD. Возможность повторить сборку не означает обещание побайтной воспроизводимости времени компиляции.

## Что проверяется на прототипе

TFT/EC11/AP, фактические времена GPIO и датчиков, чтение/запись NVS при сбоях питания, длительность финальной flash-операции, OTA reboot/pending-verify/rollback, электрические и тепловые режимы. Физические испытания не проводились.

Профиль огневого процесса по умолчанию пустой: до отдельного ввода параметров топливо запрещено. Синтетические числа тестов не являются настройками отопителя. Автокалибровка оценивает только доступную температурную динамику; две выходные термопары не измеряют CO/O2, дымность, обороты или расход. Secure Boot/eFuse/Flash Encryption не включались.
