# Историческая промежуточная запись 0.1.6-DRAFT

Эта запись сохранена как отчёт WIP-коммита. Актуальное состояние, выполненные проверки и ограничения: `../README_RU.md`, `reference_features_ru.md` и `../release/build-kits/0.1.6-esp32s3/`. Перечень ниже относится только к первому промежуточному исходнику, не к итоговому комплекту.

Карточка t_041c7f7b. Основа: main 8aed22e82b87199476af3462d34f7c29e780fda8 (50/50 исходных host-проверок). Аппаратные файлы и GPIO не изменяются.

В разработке в этой же прошивке: DS18B20 с явной коррекцией и сырым показанием; регулируемый гистерезис; отдельный допуск малого режима горения; новый ручной START после остановки; русский TFT/меню; журнал переходов и учёт команд; безопасное обслуживание Wi‑Fi STA/MQTT/TLS и OTA с RSA-3072-подписанным паспортом, SHA-256, двумя слотами и штатным rollback ESP-IDF.

Первый промежуточный ESP32-S3 target build на Lab завершился exit 0; это НЕ проверка всех последующих изменений. Промежуточные host-проверки: исходные 50/50; новые функции 10/10; UI 4/4; настоящий код MQTT/OTA-адаптера 12/12. В последних TLS, flash и RTOS подменены; RSA/SHA выполнены OpenSSL. Это не сеанс MQTT/HTTPS на ESP32 и не проверка аппаратного отката.

До завершения обязательны: итоговая чистая target-сборка точного исходника; проверка/доводка гонок START/flash/снимков и сохранения аварий; дополнительная адаптерная регрессия; свежие изображения общего рендерера; матрица источников и лицензий; операторское руководство/сервисные утилиты; полный комплект с bin, sdkconfig, исходниками, журналами и SHA256SUMS; проверка main через обратное чтение. Эта запись намеренно не объявляет перечисленные функции готовыми.

Важные границы:

- Рабочих сетевых реквизитов, доверенного ключа владельца, платы и туннеля пока нет. По умолчанию устройство автономно и сеть выключена. Приватный ключ подписи не хранится на плате или в репозитории; тестовые ключи создаются в памяти теста.
- eFuse, Secure Boot и Flash Encryption не включаются. Сервисные реквизиты, введённые позже по локальному USB, лежат в NVS; без защиты flash они не защищены от физического считывания. Это ограничение BENCH ONLY, не обещание защищённого серийного изделия.
- На старом factory-only размещении разделов нет двух слотов. Переход на эту разметку требует USB и отдельно описанного сохранения/повторного допуска профиля; прошивать на старую разметку OTA нельзя.
- Критичная схема Config теперь 3. Схемы 1/2 автоматически не принимаются и не стираются, старый допуск малого горения не переносится.
- Физические контакты реле не измеряются: показываются только команды GPIO. Времена учитываются по командам, а не по току.
- Физические дисплей/SPI/GPIO/watchdog/защёлка, Wi‑Fi/OTA и горелка не испытаны. DRAFT / BENCH ONLY.
