# Референсы и самостоятельная адаптация — 0.1.6-DRAFT

Это описание реализованного поведения, а не допуск к огневой эксплуатации. Код референсов в прошивку не переносился: доработаны существующие `Machine`, `LocalMenu`, `CommissioningStore`, драйверы и задачи ESP-IDF. Лицензия собственных материалов не менялась.

## Что проверено и чего это не доказывает

Полная регрессия: 50 baseline + 11 feature + 11 runtime + 4 UI + 17 network = 93 C++-группы; ещё 4 Python-теста сервисной утилиты. Runtime-тесты компилируют production `app_main.cpp`, NVS/output/network-тесты — реальные адаптеры с подменёнными внешними API. Криптография RSA-3072/SHA-256 проверяется OpenSSL; TLS, Wi-Fi, RTOS, flash, GPIO, SPI и otadata моделируются. Актуальные образы, SHA-256 и полный чистый ESP32-S3 build log находятся в `release/build-kits/0.1.6-esp32s3/`.

Обязательный следующий физический этап — безопасный стенд без топлива: общий SPI с раздельными CS, реальный TFT/датчики, задержки STOP/watchdog под нагрузкой, NVS/питание/два OTA-слота/rollback. Допуск горения и устойчивого малого режима этим комплектом не выдан.
