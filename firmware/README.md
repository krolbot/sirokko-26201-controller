# Прошивка

В снимке DRAFT-01 прошивки нет. Этот файл фиксирует отсутствие выпуска и не является программной заготовкой.

Проверенные исходники следует добавлять отдельным изменением вместе с закреплённой средой сборки, тестами, машинно-читаемым контрактом I/O и конфигурацией без опасных скрытых значений по умолчанию. До заполнения и принятия испытанных параметров прошивка не должна разрешать подачу реального топлива.
