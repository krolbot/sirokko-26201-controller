# Sirokko 262.01 — 0.1.8-DRAFT / BENCH ONLY

BREAKING: GPIO8 is now MCU_STOP_N input/output open drain, not a legacy NC STOP input. DO NOT FLASH existing/legacy PCB wiring: firmware LOW bypasses that contact. New draft-06 wiring must be manually integrated and checked with dangerous loads disconnected. No automatic PCB detection. Schema-3 accepted NVS cannot enable it: explicit schema-4 hardware_contract_id=6 commissioning is required. NKK BB25AB-FA is a documented functional RESET candidate; ChipDip/footprint/bracket pins and full qualification remain HOLD; four physical buttons have NOT been installed or qualified.

ESP-IDF 5.5.2 firmware for ESP32-S3-DevKitC-1-N8R8 v1.1. This is an uncommissioned bench candidate, not authorization for fired operation. No physical board was connected or flashed.

The authoritative operator/build/limitations guide is [README_RU.md](README_RU.md). See [reference matrix](docs/reference_features_ru.md), [buttons and screens](docs/operator_ui_ru.md), [commissioning](docs/commissioning_ru.md), [service/OTA API](docs/service_network_ru.md), and the new draft-06 [pin contract](docs/io-contract.json).

Version 0.1.7 previously added a qualified-profile thermostat, Russian TFT menu, calibration/command accounting/history, deferred validated NVS persistence, and separately authorized optional TLS MQTT/HTTPS signed OTA. It does not add remote ignition, automatic restart, independent pump metering, or invented measurements. Production control/runtime/adapters are exercised in 110 C++ groups (including 13 draft-06 groups) plus 4 offline service-tool tests; peripheral/RTOS/TLS/flash boundaries are injected, not physical observations.

TFT timing was corrected to 10MHz, explicit CS setup/hold and one shared 240×20 strip geometry (16 strips/frame). See [timing analysis and unverified physical limits](docs/tft_spi_timing_ru.md). The 0.1.6-DRAFT kit is [withdrawn as a final bench candidate](release/NOT_FOR_USE_0.1.6_RU.md); no physical SPI qualification was performed.

The current draft-06 bench kit is [0.1.8-esp32s3](release/build-kits/0.1.8-esp32s3/): real target build exit 0, source 3ef88c6cbd13ba83593f9e24cf222d2f79f0906b, ESP-IDF v5.5.2, full source/configuration/logs/checksums; host checks repeated from the unpacked kit. It is NOT compatible with the existing PCB. The previous separate START/STOP candidate kit is [release/build-kits/0.1.7-esp32s3/](release/build-kits/0.1.7-esp32s3/), including full source identity, real binaries, configuration, logs, simulated render images, manifest and SHA256SUMS. Older kits remain unchanged. Initial migration from the old factory-only partition layout requires USB and the NEW flash_args: the application is now at 0x20000, not 0x10000. Never flash a running heater or erase critical NVS as an automatic repair.
