# Sirokko 262.01 controller

Public DRAFT-02 WIP snapshot of the controller-interface design for a Sirokko 262.01 heater retrofit. Russian documentation: [README_RU.md](README_RU.md).

This repository is not a finished burner controller. It currently contains the editable KiCad interface schematic, an untraced PCB layout, ERC/DRC reports, renders, and project documents. It does not contain a production-ready PCB, Gerbers, a manufacturing BOM, firmware, or proof of physical or combustion safety.

Do not connect 24 V loads, the glow plug, motor, fuel-clutch coil, or a live burner directly to the published logic interfaces. Independent hardware interlocks and verified power stages are still required.

No license is granted by this repository at this stage. Third-party manuals and scans are not redistributed; the design documents contain source links only.
