# Результаты проверок

`wip-2026-10-25/` содержит проверки текущего восстановленного WIP-снимка основной схемы и PCB: ERC, DRC со сверкой схемы и платы, сведения о восстановлении и контроль целостности.

Файлы непосредственно в этом каталоге (`Sirokko26201_control-strict-erc.json`, `Sirokko26201_control.xml`, `snapshot.json`) сохранены как история DRAFT-01. `Sirokko26201_control-drc.json` и `Sirokko26201_control-erc.json` — исторические проверки старой PCB DRAFT-02 из commit `742e937a10393e87c5d4c779505e63a657a1b24b`, с 80 непроложенными соединениями, а не 182 текущего снимка. Эти отчёты не относятся к текущей схеме/PCB и не подтверждают её готовность. Исходные DRAFT-01/DRAFT-02 доступны в истории Git.

ERC/DRC не подтверждают токи, нагрев, программу, монтаж, горение или безопасность эксплуатации. Ограничения актуального снимка: `../hardware/WIP_CHECKPOINT.md`.
