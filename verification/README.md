# Проверка снимка DRAFT-01

- `Sirokko26201_control-strict-erc.json` — фактический отчёт `kicad-cli sch erc --severity-all --exit-code-violations --format json`, 0 нарушений.
- `Sirokko26201_control.xml` — экспортированный список цепей для сверки назначений.
- `snapshot.json` — состав, контрольные суммы и честные границы опубликованного снимка.

ERC проверяет только правила схемы. Он не подтверждает внутреннее устройство внешних модулей, токи, программу, PCB, монтаж, горение или безопасность эксплуатации.
