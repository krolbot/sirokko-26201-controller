# Покупной TFT 2.4″ + EC11 — окончательный интерфейс

Используется заказанный готовый модуль SPI, 3.3 В, ST7789. KEY0 не используется. BLK оставлен свободным; включение подсветки по умолчанию — допущение до проверки конкретного модуля. Точное разрешение и фактическая ревизия не подтверждены паспортом. Пайка и крепление — пользователем.

J32 — IDC 2×6, шаг 2.54 мм, кабель до 100 мм. **Подключение не 1:1.** Номера сверять по маркировке, не по цвету провода.

- Модуль 1 GND → J32.1 либо J32.4.
- Модуль 2 VCC → J32.2, +3.3 В.
- Модуль 3 SCL/SCK → J32.5, GPIO8/J1.12.
- Модуль 4 SDA/MOSI → J32.3, GPIO7/J1.7.
- Модуль 5 RES → J32.9, GPIO6/J1.6.
- Модуль 6 DC → J32.10, GPIO41/J3.7.
- Модуль 7 CS → J32.11, GPIO42/J3.6.
- Модуль 8 BLK → не подключать в текущем варианте.
- Модуль 9 A → J32.6, GPIO5/J1.5.
- Модуль 10 B → J32.7, GPIO38/J3.10.
- Модуль 11 PUSH → J32.8, GPIO47/J3.17.
- Модуль 12 KEY0 → не подключать; J32.12 также NC.

PANEL_SDA/PANEL_SCL означают отдельный SPI дисплея, не I²C. SPI MAX31856 и его CS GPIO9/10 сохранены. GPIO3 и GPIO46 на несущей плате NC: GPIO46 — только вход, для TFT_CS непригоден. GPIO41/42 выбраны как свободные выходы; их возможную функцию внешнего JTAG при настройке TFT отключить программно. На работу встроенного USB это назначение не распространяется.

Расположение выводов сверено по схеме **YD-ESP32-S3 V1.4**, а не по порядковому номеру контакта колодки. J2 изготовителя соответствует J3 несущей платы:
https://raw.githubusercontent.com/vcc-gnd/YD-ESP32-S3/main/5-public-YD-ESP32-S3-Hardware%20info/YD-ESP32-S3-SCH-V1.4.pdf

Ограничения ESP32-S3:
https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/schematic-checklist.html

Все 252 электрических назначения схемы сверены с PCB. Отдельный функциональный контроль выявляет старую ошибку CS на GPIO46 и принимает новую карту. Прошивка не менялась: её драйвер дисплея и обработка энкодера не считаются реализованными этим аппаратным комплектом.
