# Готовая панель TFT2.4 + EC11 — текущий интерфейс

Пользователь заказал модуль2.4inch. По изображениям описания:ST7789,SPI,питание3.3В; BLK включён по умолчанию. Пайку/крепление выполняет пользователь. KEY0 не используется. Точное разрешение и фактическая ревизия модуля физически не проверялись.

J32 — IDC2×6,шаг2.54мм,кабель≤100мм. Соединение1:1 НЕ подходит.

- Модуль1GND → J32.1 либо.4.
- Модуль2VCC → J32.2,+3.3В.
- Модуль3SCL/SCK → J32.5,GPIO8.
- Модуль4SDA/MOSI → J32.3,GPIO7.
- Модуль5RES → J32.9,GPIO6.
- Модуль6DC → J32.10,GPIO9.
- Модуль7CS → J32.11,GPIO10.
- Модуль8BLK — свободный, подсветка включена по описанию.
- Модуль9A → J32.6,GPIO5.
- Модуль10B → J32.7,GPIO38.
- Модуль11PUSH → J32.8,GPIO47.
- Модуль12KEY0 — свободный; J32.12 такжеNC.

PANEL_SDA/PANEL_SCL теперь означают SPI дисплея,неI²C. ОтдельныйSPI MAX31856 не менялся. Все252pin-net полногоXML сверены с текущейPCB. Прошивка не менялась; аппаратное подключение не означает реализованныйдрайверэкрана.
