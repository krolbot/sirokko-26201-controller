## Проверенная геометрия

Посадки прочитаны непосредственно через pcbnew на Lab. Все органы управления установлены со стороны B.Cu.

Центры в системе координат PCB, мм:
- J23, энкодер: **X102.00; Y128.00**.
- J22, ПУСК/СТОП: **X102.25; Y146.50**.
- J24, RESET: **X96.00; Y163.00**.

У J22 начало координат посадки `(96;149)` находится на контакте, а не в центре кнопки. Центр прямоугольного рисунка выводов: `((96+108.5)/2; (144+149)/2) = (102.25;146.50)`. Использование начала посадки для проёма дало бы ошибку −6.25 мм по X и +2.50 мм по Y.

Центры внесены невидимыми полями `Panel_Actuator_Centre_X_mm` и `Panel_Actuator_Centre_Y_mm` в соответствующие посадки PCB. После сохранения файл повторно открыт, поля прочитаны обратно. Положение компонентов, отверстия, трассы и назначение сетей не менялись.

У энкодера проверены две NPTH-прорези 1.5×2.6 мм с центрами `(96.5;128)` и `(107.5;128)` мм. Требуемый допуск длины прорези +0.1/0 мм — требование к изготовлению, не предположение о процессе завода.

У TFT проверены четыре NPTH Ø2.7 мм: `(27;129.75)`, `(85;129.75)`, `(27;157.75)`, `(85;157.75)`. Габарит PCB модуля: X25…87, Y125…162.25 мм. Ряд J26: X84.20, Y136.29…151.53 мм, шаг 2.54 мм.
