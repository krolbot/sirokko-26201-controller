## Конкретный дефект

Из native-текста замороженной PCB прочитан DS1 на B.Cu, origin (196.45;118.425), rotation 180°. Контур окна в Dwgs.User: local start(-1;+1), end(71.5;−44.3). Подпись: PANEL WINDOW 72.5x45.3 / 1.0 CLEARANCE / BY OUTER ENVELOPE, NOT AA.

При записанной геометрии native-преобразование x=196.45−u, y=118.425−v. Номинальные границы окна, мм:
- X=124.95…197.45;
- Y=117.425…162.725;
- размер 72.50×45.30.

B-side операторский вид отражает native X: правый край окна для оператора соответствует native Xmin=124.95. Текущие физические центры J23/J22/J24 имеют общую native ось X=68.00. Для J22 origin(61.75;142.5) не равен центру: B.Fab fp_circle center(6.25;−2.5) даёт физический центр(68.00;140.00).

Проверенный размер:
`d = X_window_min − X_axis = 124.95 − 68.00 = 56.95 мм`.
Это на 3.05 мм меньше обязательных 60 мм. Старый root gr_text CONTROL AXIS X=68.0; 60.0 FROM WINDOW RIGHT неверен для нового окна. Одновременно присутствует старый root gr_text PANEL CUTOUT 66.4 x 46.0; PLANE Z=8.5 — он противоречит новому окну и не может быть инструкцией изготовления.

У J22 также остались скрытые свойства Panel_Actuator_Centre_X_mm=102.25 и Y_mm=146.50. Они не соответствуют фактической текущей геометрии. Их нельзя использовать для панели или следующего экспорта.

## Один рекомендуемый controlled change

Не двигать DS1, H7–H10 и не менять экран/колпачки/схему ради этого размера. Перенести всю колонку J23/J22/J24 на ΔX_native=−3.05 мм, ΔY=0.00, сохранив сторону/повороты и физические шаги 30 мм.

Новая общая физическая ось:
`X_axis = 124.95 − 60.00 = 64.95 мм`.

Целевые origins (мм):
- J23 (64.95;110.00);
- J22 (58.70;142.50), физический центр (64.95;140.00);
- J24 (64.95;170.00).

Обновить зависимые подписи и свойства центров из геометрии, не оставлять два противоречивых источника. Старую разметку окна66.4×46 убрать/заменить в рабочем исходнике с сохранением истории Git; высоту8.5 не объявлять принятой Z-цепью. Отдельно повторно открыть результат в KiCad и проверить трансформацию окна по углам и реальные центры органов; вычисленный перенос ещё не применён.

Перенос затрагивает имеющуюся медь: разрешена только адресная местная переразводка затронутых выводов с сохранением всех текущих net/pin/UUID, без remove_dangling_tracks. Проверить соседей, край PCB, отверстия, доступ ручки, полный native connected pairset и full DRC/ERC/parity. Если сохранить локальные связи без конфликта невозможно, вернуть адресную причину; не менять ось или модуль молча. Не начинать общую трассировку/прошивку.

Положительный геометрический контроль после исправления: 124.95−64.95=60.00 мм; центры Y110/140/170 дают шаг30/30. Отрицательный контроль: прежняя ось68 даёт56.95 и должна отвергаться даже при старой надписи «60.0».

## Что эта коррекция не закрывает

72.5×45.3 — назначенное окно по наружному envelope, не документированная AA и не квалифицированный допуск покупного модуля. Требуются окончательная увязка панели/TFT/крепежа/кабеля, высотная доступность кнопок, relay/socket installed geometry и прочие критерии исходного единого handoff. Поднимать TFT или менять органы ради одной плоской панели этой коррекцией не разрешено.

В README архива следующий шаг включает «физическое измерение relay/socket/TFT stack». Это не основание требовать от пользователя образцы/замеры до проектирования: такой запрос исключён текущими условиями. Продолжать документальный подбор и назначение собственных деталей/условий сборки; фактическую проверку первого изготовленного изделия вынести в будущую приёмку, не подменяя ею недоделанную проектную работу.

Итог: целостность frozen handoff подтверждена; найден и рассчитан конкретный несоблюдённый UX-размер. `layout_accepted=false`, `production_release=false`; CAD этим аудитом не записывался. Исправление должен внести единственный владелец последовательной CAD-операции; второй CAD writer не создаётся.

Ограничение инструмента: sexpdata недоступен (ModuleNotFoundError), установка не выполнялась. Использованы чтение native-текста точных целевых footprint-блоков и Decimal-расчёт; собственного native KiCad-прогона этот аудит не заявляет.
