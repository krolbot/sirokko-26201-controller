# Sirokko — геометрия местной панели отменена

Статус: исторический документ прежней ревизии. Последнее прямое требование пользователя отменяет экран, кнопку ПУСК/СТОП, энкодер, их крепёж, окно и всю взаимную геометрию панели.

Прежние размеры 60 мм, 30 мм, 86 мм, окно 52 мм, координаты органов и расчётный охват руки больше не являются требованиями к CAD, корпусу, BOM или прошивке. Их происхождение сохраняется в истории Git; переносить эти размеры в PCB нельзя.

Управление, уставки и диагностика теперь требуются только через собственную точку доступа ESP32 и панель в браузере. Действующие документы:

- [`REQUIREMENTS_RU.md`](REQUIREMENTS_RU.md);
- [`UX_PANEL_REQUIREMENTS_RU.md`](UX_PANEL_REQUIREMENTS_RU.md);
- [`../hardware/kicad/REMOTE_ONLY_REQUIREMENTS_RU.md`](../hardware/kicad/REMOTE_ONLY_REQUIREMENTS_RU.md).

В действующей PCB геометрии отменённых экрана, кнопки, энкодера, отдельного RESET и внешнего watchdog нет. DRAFT / NOT FOR ORDER / NO POWER / NO FLASH / NO FIRE; firmware HOLD.
