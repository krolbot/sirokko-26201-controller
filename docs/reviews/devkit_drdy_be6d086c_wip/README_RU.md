# Sirokko — восстановление двух DRDY после переноса DevKit

**DRAFT / NOT FOR ORDER / NO POWER / NO FIRE**

Локальный ручной CAD-подпроход BE6D086C от frozen 6CA123BC. Это не основная PCB, не принятая компоновка и не производственный комплект. Прошивка не менялась, общая разводка не начиналась.

Восстановлены два независимых соединения: U10.7 → J3.5 (TC_AIR_DRDY) и U9.7 → J3.4 (TC_EXH_DRDY). Добавлены только шесть сегментов шириной 0,25 мм, без новых via. AIR проходит по B.Cu, EXH по F.Cu; вертикальные участки X=77,75 мм, правее существующего SAFETY_OK_RAW via (77;26) мм. Старая медь не удалялась и не переименовывалась. Сеть EN_CHIP_PU не восстанавливалась вслепую: native readback обнаружил единственную площадку J1.3, схемное предупреждение остаётся открытым.
