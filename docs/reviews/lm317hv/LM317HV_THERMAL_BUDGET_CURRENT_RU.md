## Расчёт

Vout = Vref×(1+R9010/R9009)+Iadj×R9010.

Получен статический диапазон 11.606115…13.732852 В. При входе21.6В минимальный запас Vin−Vout=7.867148В, больше3В применимости статического допуска. Название VDRV12V не означает точные12.000В. Совместимость LTC7001 и затвора с полным диапазоном/переходными процессами проверяется отдельно.

Минимальный ток верхнего резистора 1.2/76.73475=15.638286мА; максимальный1.3/73.28475=17.739025мА. Делитель постоянно потребляет ток даже при OFF двигателя. Ниже его ток уже включён; повторно прибавлять его к этим результатам нельзя.

Для строгой консервативной верхней оценки приняты независимые экстремумы:
P_U9007 ≤ (28.8−Vout_min)×(I_external+Idivider_max)+28.8×105мкА.

Последнее слагаемое завышает потери ADJ, не вычитая мощность, выходящую через ADJ. Это сознательная верхняя оценка, а не точный измеренный нагрев.

- Без внешней нагрузки: P≤0.308027Вт; с25% запасом0.385033Вт.
- Внешняя нагрузка10мА: P≤0.479966Вт; с25%0.599957Вт.
- Внешняя нагрузка25мА: P≤0.737874Вт; с25%0.922342Вт.

Эти10/25/50мА — проверочные сценарии, НЕ измеренное потребление и не уже введённый предел работающей платы.

Требование к фактическому эффективному тепловому сопротивлению:
θ_effective ≤ (125−Ta)/(1.25×P_upper).

При условном Ta=60°C:

## Решение для дальнейшей интеграции

Не заменять LM317HV и не добавлять радиатор по одному названию TO220. Сначала закончить реестр реальной нагрузки VDRV по действующему диапазону PWM; затем сравнить её с приведённым допустимым тепловым режимом текущего монтажа. При необходимости назначить теплоотвод/площадь и повторить расчёт, сохраняя электрическую изоляцию металлической части VOUT. Нельзя принимать23°C/Вт из таблицы без применимости к монтажу.

Регулятор остаётся в статически достаточном диапазоне входного запаса; тепловая приёмка открыта до установления тока драйвера и эффективного теплоотвода. Пуск, импульсная SOA, входные выбросы, обратные токи и VCC/UVLO LTC7001 этим не закрыты. Запрет общей трассировки/прошивки до layout acceptance сохраняется.
