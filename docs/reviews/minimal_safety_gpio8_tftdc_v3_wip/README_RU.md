# Sirokko — TFT_DC на GPIO8, V3
DRAFT / NOT FOR ORDER / NO POWER / NO FIRE

## Принятый готовый модуль
ESP32-S3-DevKitC-1 N16R8 с U.FL / IPEX (IPX). Пользователь подтвердил одинаковые с YD плату, размеры колодок и контакты; отличие — внешняя антенна. Сохраняем две колодки22контакта, шаг2,54мм, межрядье25,40мм. Повторных фото/измерений для подтверждения этого исходного данного не требуем. Антенный эксперимент V2 отклонён и сюда НЕ включён: четыре Edge.Cuts полностью совпадают с V1, никакого выреза.

## Исправление
Прежняя TFT_DC на GPIO48 требовала отключения RGB на DevKit. Готовый модуль переделывать не нужно: TFT_DC назначена на свободный GPIO8, J1.12. J3.16/GPIO48 теперь no_connect на Sirokko, встроенный RGB остаётся штатным. Назначения GPIO8 как прежнего STOP_MONITOR нет, его удалили при минимизации аппаратной логики. Нельзя заливать старую прошивку: она несовместима. Новая прошивка — только после окончания платы.

Изменены ровно два pin/net-контракта; U303.12 по-прежнему вход TFT_DC, J26.6 остаётся TFT_DC_BUF. Остальные назначения из полного XML netlist сохранены. Существующие33copperrecords старой TFT_DC демонтированы адресно и сохранены в журнале. Оставшиеся1716tracks/vias сохранены по UUID/net/геометрии/ширине/слою. Размеры/положение/состав footprint/pads не менялись. Изменены только сети двух площадок; подписи J1/J3 перенесены внутрь кромки. Это подготовка к более простой новой трассе, а не уже восстановленная физическая связь. Общая разводка до готовой единой компоновки не начиналась.

## Проверено
Fresh native netlist: ровно J1.12 и J3.16 изменены. ERC0/0 при существующих настройках проекта. PCB DRCexit5:121unconnected,79track_dangling+5via_dangling,0прочихerrors,0parity. Это НЕ чистый DRC/не завершённая плата. Зоны заполнены и сохранены перед DRC. Антенный вырез отсутствует, четыре Edge.Cuts совпадают с V1.
BOARD_TOP_DRAFT.png и BOARD_BOTTOM_DRAFT.png — проверенные полные native виды, не изображение готовой сборки. Выноски управляющих элементов на нижнем виде привязаны к фактическим native координатам, зеркальное преобразование сверено по четырём Reference. HEADER_GPIO8_DETAIL.png подтверждает TFT_DC у J1.12/no_connectJ3.16; старые тесные подписи питания на этом листе ещё требуют оформления.
