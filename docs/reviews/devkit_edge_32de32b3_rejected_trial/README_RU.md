## Полный DRC и решение

Свежий KiCad10.0.7 CLI DRC: --format json --all-track-errors --schematic-parity --refill-zones --exit-code-violations. Реальный exit5:164violations,78unconnected,0schematicparity.

Состав:44solder_mask_bridge,44shorting_items,48hole_clearance,6clearance,1silk_over_copper,20track_dangling,1via_dangling. Edgeclearanceнарушений у второго варианта нет. Это не принятие: перенос площадок поверх прежней меди создал новые конфликты/КЗ и nativeпереназначениясетей. Полезная медь радиPASS не удалялась, исходнаяPCB не менялась. ERC повторно не запускался: схема неизменна.

**Решение:** направление переноса позволяет вынести антенну наружу, но сам кандидат электрически отклонён. Не заменятьlatestPCB, не называтьlayoutcomplete. Нужна адресная переработка местноймеди с сохранением исходныхсетей/функциональныхгрупп и полнымDRC, затем проверка единойкомпоновки. Общаяразводка и firmware до завершениякомпоновки остаются приостановленными. НеподтверждённаяZгеометрия ограничивает приёмкусборки, но не запрещает независимуюработу над размещением/местноймедью.
