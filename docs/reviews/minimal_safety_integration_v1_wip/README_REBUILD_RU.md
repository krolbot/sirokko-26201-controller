Это согласованный снимок схемы и промежуточной PCB, НЕ производственный комплект и НЕ замена принятой основной PCB. Исходный frozen PCB c7a4eca2 сохранён. Общая компоновка не принята, общую разводку и прошивку не начинать.

## Выполнено
- Прежняя логическая группа заменена на U1 TPS3431, U2 SN74HCS74, U6 SN74HCS11; драйвер катушек U11 DRV8803 сохранён. Большинство защит процесса остаются задачей ESP32.
- Из PCB удалены 25 исключённых из схемы деталей, добавлены четыре резистора R700–R703. В схеме 147 компонентов, на PCB вместе с 13 механическими отверстиями 160 посадочных мест.
- Старая медь изменённого блока демонтирована адресно по журналу. Для перемещаемых деталей разрезаны прежние подключения питания и освобождены места нового размещения. Это создаёт незавершённые соединения и НЕ улучшает готовность электрического изделия само по себе.
- 1749 оставшихся дорожек/переходов проверены по UUID, сети, координатам, ширине и слою; непредусмотренных изменений нет. Посадочные места сопоставлены с новой схемой.
- Повторное обновление PCB из схемы идемпотентно. Крепёжные отверстия не удалены как stale.
- Подписи нового блока исправлены в native PCB; конечное изображение осмотрено.

## Проверка
- Схема: native_acceptance.json и erc.json — 0 ошибок / 0 предупреждений при сохранённых настройках проекта. Отключённые в проекте классы перечислены в evidence; это не утверждение об абсолютно всех проверках.
- PCB: свежий DRC exit 5, 121 unconnected items, 81 track_dangling, 5 via_dangling, 0 schematic parity issues; других ошибок DRC в этом запуске нет. Не считать DRC чистым!
- pcb_final_native_checks.json относится к конечному PCB. pcb_rebuild_ledger.json содержит начальный план размещения; действующие координаты в pcb_final_native_checks.json. pcb_native_placement.json — промежуточный журнал до перестановки трёх конденсаторов.
- negative.xml — намеренно испорченная контрольная схема, не проект для изготовления; результаты в native_negative_control.json.
- CORE_PLACEMENT_DETAIL.png — только фрагмент размещения, не изображение готовой разводки.
