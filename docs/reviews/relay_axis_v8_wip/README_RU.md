# Sirokko V8 — исправление осей габарита DG85BM

DRAFT / NOT FOR ORDER / NO POWER / NO FIRE

## Исправленный дефект

Продолжение V7, не альтернативная конструкция. В прежнем F.Fab для K1/K2/K3 габариты корпуса были переставлены по осям относительно направления от контакта 87 к 30. Размерный чертёж Durakool DG85BM 01-Jul-2026 FW, Fig.1, физическая стр.2 показывает поперёк этой оси 30,5 MAX, вдоль 35,0 MAX и от верхней границы до центра 87 размер 9,0 REF. Поэтому прежний контур X=±17,5; Y=-4,5…26 мм не показывает верхнюю полосу шириной 4,5 мм и избыточно расширен по X.

Исправлено непосредственно в трёх экземплярах PCB и соответствующей project-local библиотеке:
- F.Fab: X=-15,25…15,25; Y=-9…26 мм;
- F.Courtyard: сохранён прежний широкий X=-18,5…18,5; верх расширен до Y=-10, низ оставлен Y=27 мм;
- общий проектный VRML-резерв: расширен с 35×30,5×56 до 35×35×56 мм, центр смещён по Y так, чтобы он покрывал исправленную область. Масштаб legacy VRML 2,54 мм и инверсия Y учтены. Этот параллелепипед НЕ является CAD изготовителя, точной сборкой колодки/реле или гарантированным допуском установленной высоты.

9 REF — справочная привязка, не индивидуально допущенный монтажный размер. Контур — восстановленная геометрия по reference drawing, не гарантированный предельный envelope по всем допускам. Боковой запас courtyard намеренно не уменьшен. Новая геометрия устраняет конкретную ошибку ориентации, но не квалифицирует сопряжение колодки с реле.

## Что не изменено

Положения и углы K1/K2/K3, их площадки, номера/сети, все остальные компоненты, все дорожки/via и Edge.Cuts прежние. Не перемещать корректно расположенные колодки/медь ради ошибки внешнего контура модели. Изменены только три проектных файла: PCB, один library footprint, один собственный WRL. Схемы и номиналы не менялись; новая прошивка не начата. Старые frozen V6/V7 не переписывать. Canonical/latest PCB не заменена.

## Проверка

Свежий native reopen/fill/connectivity KiCad 10.0.7: 1717 объектов track/via, 603 физических PAD, 158 footprints. Полные PAD/track/via/zone connected components, медь по UUID/координатам/слоям/ширинам/сетям, все параметры PAD и размещение компонентов совпадают с V7. NATIVE_ACCEPTANCE.json и EDIT_LEDGER.json содержат числа, исходный/новый SHA и шесть исправленных прямоугольников.

Одинаково запущенный свежий полный DRC базы и кандидата: оба exit5; 86 обычных violations (81 track_dangling,5 via_dangling),117 unconnected,0 schematic parity. Полные multiset обычных violations одинаковы; endpoints airwires частично отличаются при прежней полной native-связности — не выдавать их за идентичный отчёт. Поскольку все схемные bytes прежние, ERC на этом шаге не перезапускали; V7 имела 0 нарушений.

Предварительный XY-screen расширенных трёх courtyard против native bounding boxes остальных F-side деталей не обнаружил пересечений. Это не расчёт высоты, захвата рукой, прогиба платы или усилия извлечения. Положительный/отрицательный контроль: точка (0;-8,5) внутри нового reference-контура, но вне старого. Реле не перемещались. Исправление рисунка не доказывает ни работоспособность, ни правильность прежней электрической карты колодки.

RELAY_AXIS_REVIEW.svg/png получены из свежего native SVG: все K1/K2/K3 целиком. Красный пунктир — старый F.Fab, зелёный — исправленный; окружающая графика частично обрезана как на локальном фрагменте. Это сравнительная иллюстрация, не производственный сборочный чертёж.

## Дальнейшие незакрытые критерии

Глубина сопряжения, гарантированная установленная высота, действительный захват/снятие, опирание PCB при извлечении, точная контактная карта DZ85AB, закупаемость exact MPN, ток/нагрев/ресурс и индуктивная DC-коммутация не квалифицированы этим шагом. Высота 56 мм остаётся только прежним собственным предварительным резервом. Отсутствие 3D-коллизии не объявляется; полная компоновка и весь проект не завершены. 117 соединений не разведены. Производство, питание, физическая прошивка и огневые испытания не разрешены.
