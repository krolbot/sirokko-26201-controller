## Применённое изменение

Единственная рабочая PCB: `hardware/kicad/Sirokko26201_control_motor_candidate.kicad_pcb`.
- Исходный опубликованный commit: `bf43e90c7fb998f3001712ecb7e52fbc3fe97cd6`.
- Исходная PCB SHA-256: `6b468c5fa23f7dce844ba41a267a18a37fbd6e21685c135afdaadc7fb7f77b5e`.
- Новая PCB SHA-256: `ede60af2ec3cc225c12836b2bf58f1e7a909507fb97195a61841afc22681ad20`.
- J1: X=100.45 мм, Y=100.9 мм; J3: X=100.45 мм, Y=75.5 мм. Обе колодки: 90°, B.Cu.
- Расчётная охватывающая рамка DevKit: X=37.06…110.50 мм, Y=74.23…102.17 мм. До ближайшего согласованного габарита MAX31856 — 29.69 мм. Это геометрический зазор, не испытание помехоустойчивости.
- R1 оставлен на прежнем месте. Колодки и крепёжные отверстия MAX31856 не изменялись; стойки и винты подбирает пользователь.
- Контур сохранён: 305×170 мм. Экран, местные органы и их крепление не возвращались.

Заново подключены ROOM_DQ, питание DevKit и периферии, земля, семь цепей MAX31856 и четыре управляющие цепи свечи, муфты и внешнего HC160. Сохранены полезные общие SPI-участки, обе подтяжки CS, существующая ветвь R1—J12 и полезные силовые магистрали. Адресно удалены только выбранные старые участки, включая проверенные свободные хвосты.

## Реально выполненные проверки

KiCad 10.0.8; проверки относятся к новой записанной PCB:
- Native refill/reopen и полный DRC инструмента: exit 0, 0 нарушений, 0 разрывов.
- Независимое повторное чтение DRC после записи: exit 0, 0 нарушений, 0 разрывов.
- ERC корневой схемы со всей иерархией: 0 нарушений.
- Состав: 70 посадочных мест, 287 площадок, 615 сегментов, 140 переходов, 27 зон.
- По сравнению с исходником: сегментов 617→615, переходов 139→140. Абсолютный минимум переходов не заявляется.
- Физические PAD-группы проверены native BuildConnectivity/GetConnectedItems(PAD,0): 240 медных площадок образуют 77 полных непересекающихся групп; 47 немедных площадок учитываются отдельно в полном составе.
- Набор 1600 неупорядоченных пар связанных площадок совпадает с исходным точно: 0 потерянных и 0 добавленных. UUID, номера и сети всех 287 площадок сохранены.
- 670 защищённых прежних медных объектов сохранили native геометрию, слои и сети. Все неперемещаемые посадочные места сохранились.
- Отрицательный контроль новой ROOM-дорожки на отдельной несохраняемой native-модели: отведение именно новой ветви разрывает J1.4↔R1.2 и J1.4↔J12.2, но сохраняет R1.2↔J12.2. Рабочая PCB этим тестом не изменена.
- Все видимые обозначения Reference нативно проверены по полным графическим рамкам: за внешний контур не выходят.

Проверка физической связности дополняет DRC, а не заменяет проверку замыканий между разными сетями. Назначения GPIO и силовая логика не менялись. R108/C109 по-прежнему являются отдельным схемным WIP; перенос ESP не включает их интеграцию и не объявляет нулевой PCB↔SCH parity без отдельного запуска.

## Что ещё не закончено

Полная аппаратная приёмка питания/защит/силовых путей и запуска, новая прошивка с AP и браузерной панелью, её программные испытания и окончательный производственный комплект. Старая прошивка не применяется. USB предназначен только для прошивки вынутого DevKit; при работе ESP32 питается от Sirokko. Двигатель и его силовая проводка остаются полностью вне основной PCB. Физические питание, прошивка, релейные, моторные и огневые испытания не выполнялись и этим документом не разрешаются.
