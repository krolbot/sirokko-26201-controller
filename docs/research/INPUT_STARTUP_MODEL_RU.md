## Расчёт

Инструментальный расчёт, не измерение. Для разряженной прямой ёмкости и U=28,8 В:

```
Q = COUT × U = 12,5136 мКл
E = COUT × U² / 2 = 180,19584 мДж
Icap = COUT × IHGATE / CdVdT
tramp_ideal = U × CdVdT / IHGATE
```

При C109=33 нФ и типовом IHGATE=55 мкА: **Icap=0,7241667 А; идеальная рампа=17,28 мс**. Прежние 12 нФ были предварительной арифметической пробой без MPN; для дальнейшего схемного кандидата они отменены, не являются альтернативной действующей спецификацией.

Предварительная консервативная оболочка C109: начальные ±5%, TКЕ25…125°C ±0,3%, отдельная холодная −0,24/+0,58%, изменение после пайки ±2,5%, после ресурсного теста ±3%, drift ±0,2% перемножены. Одновременное применение обеих температурных поправок намеренно избыточно. Это инженерная оболочка по отдельным паспортным испытаниям, не гарантия срока службы в отопителе. Получено **29,430391…36,978102 нФ**. При IHGATE=39…75 мкА идеальная рампа **11,30127…27,30691 мс**. Собственные затворные заряды, фронты и обратное влияние нагрузки исключены: эти числа нельзя использовать как гарантированный тайм-аут пуска.

Для проверки чувствительности назначено COUT≤550 мкФ — пока не доказанный точными паспортами всех пяти деталей предел. Тогда Icap≤1,401613 А. LM5013 имеет пиковый порог ограничения 3,7/4,2/5 А по таблице при VIN=24 В; это не гарантированный максимум мгновенного входного тока всей схемы при пуске. Нельзя автоматически заменить ток нагрузки произвольными 2 А или считать порог 5 А идеальной отсечкой без задержки.

Проверена условная оболочка первого монотонного пуска: **R104=100 кОм и R105=10 кОм ±1%**. Их назначение подтверждено реальными площадками: R104.1=P24_PROTECTED, R104.2=R105.1=EN_LOGIC, R105.2=GND. R106/R107 к этому делителю не относятся (ripple injection/PGOOD). С порогом EN rising min1,43 В и только начальными допусками резисторов получается VPROTECTED_enable_min=15,446832 В. Токи входа EN, температурный/ресурсный дрейф делителя этим предварительным числом не охвачены. До этого buck условно считается выключенным; после разрешения назначен проверочный входной ток buck≤6 А, **не паспортная гарантия**. При UIN=28,8 В:

```
P_FET_before ≤ UIN × Icap = 40,36644 Вт
P_FET_after ≤ (UIN−Venable_min) × (Icap+6 А) = 98,83498 Вт
TJ_screen ≤ TC + RthJC_max × P
при TC=100°C и RthJC_max=0,4 К/Вт: TJ_screen≤139,53399°C
```

Вся мощность назначена ОДНОМУ из Q3/Q4: равномерное деление между параллельными ключами не предполагается. Это только условная тепловая проверка, близкая к абсолютному TJmax150°C и не имеющая достаточного обоснованного рабочего запаса. Не называть её SOA PASS. Для немонотонного пуска/повторного включения rising-порог не является универсальной нижней границей: нужно отдельно учитывать EN falling, уже запущенный buck и заряженные выходы.

R108: максимальный установившийся перепад от IHGATE при 22 кОм и начальном допуске +1% равен 1,6665 В, RC по начальным допускам и верхней оболочке C составляет 0,821653 мс. Температурный/ресурсный дрейф R и динамическая устойчивость этим не квалифицированы. Зарядившийся C109 не должен удерживать HGATE при аварийном отключении; проверить точные sink-токи/напряжения и worst-case deltaV на R108.

```
Rmin = 22 кОм × 0,99 = 21,78 кОм
I_RC(0+) = ΔV / Rmin
при ΔV=14,5 В: I_RC=0,665748 мА; P_R(0+)=9,653352 мВт
при полном условном скачке ΔV=79,5 В: I_RC=3,650138 мА; P_R(0+)=0,290186 Вт
τmax = 22,22 кОм × 36,978102 нФ = 0,821653 мс
t_1% = ln(100) × τmax = 3,783854 мс
E_RC = Cmax × ΔV² / 2:
  14,5 В → 3,887323 мкДж; 79,5 В → 116,855425 мкДж
```

14,5 В — верхняя паспортная величина HGATE−OUT. 79,5 В=65+14,5 В — только искусственная оболочка полного разряда при предельной рабочей шине, не штатное напряжение проекта, не разрешение эксплуатации на 65 В и не граница всех возможных выбросов.
