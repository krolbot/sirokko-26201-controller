## Геометрия и ограничения

Чертёж SSW: 22 позиции, шаг 2,54 мм; высота корпуса 8,51 мм; ширина 2,41 мм REF; длина L=N×2,54+0,51±0,25 мм. Расчёт инструментом: для N=22 L=56,39±0,25 мм, верхняя граница 56,64 мм. Выступ хвоста lead-01: 2,64 мм с общим допуском чертежа ±0,13 мм. Сечение хвоста указано 0,031×0,016 дюйма [0,79×0,41 мм] REF. Номинальная диагональ sqrt(0,79²+0,41²)=0,890056178 мм; это НЕ максимальный размер с учётом допусков.

В чертеже обнаружена внутренняя ошибка: строка THICKNESS буквально содержит .0160±.001 [0.635±0.03]. Перевод единиц не согласован с .016 [0.41] рядом с хвостом. Не исправлять эту строку молча и не выводить гарантированный размер хвоста из противоречивого примечания.
