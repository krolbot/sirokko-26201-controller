## Происхождение и проверка

Входы взяты из принятой аппаратной базы `6355f1b6e5cc8125d11e6f9f1e596a3bceb7b013` и побайтно совпали с теми же CAM-файлами в `42e3fe853f37ca86bba4f099051cf6634f463d89`. Все 11 файлов сверены по Git blob; SHA-256 каждого повторно проверен внутри браузера перед открытием. Полные хеши и параметры — в [`copper-images-current.json`](../../manufacturing/current/checks/copper-images-current.json).

Gerber/NC drill открыт в официальном [Tracespace View](https://tracespace.io/view/), стабильная ветка main/v4, MIT; разработка upstream приостановлена. По документации входные файлы обрабатываются в браузере без отправки серверу просмотрщика. Параметры формата и единицы принудительно не переопределялись. Сообщение о двух неотрисованных слоях относится только к пустым `B_Silkscreen` и `B_Paste`: в исходниках обоих нет операций D01/D03.

SVG получены штатным скачиванием просмотрщика. PNG сформированы уже установленным `rsvg-convert 2.58.0`; границы исходного рисунка меди 303,999×168,999 мм размещены в исходном поле платы с отступом 0,5005 мм. Матрицы преобразования обоих исходных SVG одинаковы: только перевод оси Y из Gerber в SVG, без отражения X. Проверены CRC PNG, внутренние ссылки SVG, размеры и визуальная целостность обоих конечных PNG. Видны дорожки, площадки, зазоры и полигоны; явной обрезки или крупного сбоя отображения нет.
