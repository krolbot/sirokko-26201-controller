# Sirokko — приёмка увеличения площадок переходов

Статус: **DRAFT / NOT FOR ORDER / production_release=false / physical_tests=false**.

## Результат

Каноническая PCB изменена адресно: у 75 из 103 переходов 0,60/0,30 мм диаметр площадки увеличен до 0,80 мм. Отверстия 0,30 мм, UUID, координаты, цепи и слои сохранены. Ещё 28 переходов оставлены 0,60/0,30 мм из-за конфликтов полного набора.

- SHA256 до: `9e10942d0e3e27358864b34ea380bc3fc3f7fcc24002788059a10cb5a8bf0444`.
- SHA256 после: `1b7a0936d9b96aaec3050cd86b12ce0b6929f403520aee953a22be1cb03e8a96`.
- Состав после: 70 посадочных мест, 287 площадок, 633 сегмента, 145 переходов, 27 зон.
- Переходы после: 28 × 0,60/0,30; 75 × 0,80/0,30; 35 × 0,80/0,40; 6 × 1,00/0,50; 1 × 0,70/0,30 мм.

## Отбор безопасного поднабора

Независимая предварительная проверка «дорожки + переходы» выявила 27 затронутых кандидатов и 46 направленных взаимодействий; это не число native DRC-нарушений и не окончательная приёмка. Полный временный кандидат из 103 увеличений затем проверен KiCad 10.0.8 с реальными правилами проекта и перезаливкой. Он дал 41 нарушение зазора, затрагивающее 28 кандидатов. Дополнительный, не покрытый предварительной геометрией конфликт — переход `/INPUT_PROTECTION_WIP_NOT_QUALIFIED/VIN_FUSED` UUID `5050cce6-fcc0-4d06-a81c-bf81b9aefdae` с площадкой U13.1 UUID `3e988bdb-7aa9-4dab-acf4-642cac0e117b`: требовалось 0,2000 мм, фактически 0,1562 мм.

Показательный отрицательный контроль: переходы `/FUEL_CMD` `(252,7575; 26,2465)` и `/GLOW_CMD` `(253,5692; 26,4290)` при одновременном увеличении оставляют только 0,031963425 мм. Оба сохранены 0,60/0,30 мм.

## Нативная проверка применённого набора

После изменения выполнены сохранение, перезаливка, повторное открытие и независимое чтение через MCP:

- native DRC: 0 нарушений, 0 незамкнутых соединений;
- отдельная проверка соответствия схеме: код 5, геометрические нарушения 0, разрывы 0, ровно два прежних `missing_footprint` — C109 и R108;
- наборы UUID всех дорожек и переходов сохранены;
- 633 сегмента не изменены;
- посадочные места, площадки, имена сетей и набор UUID зон не изменены;
- изменены ровно 75 объектов типа via, и у каждого единственное изменение — `diameter_mm: 0.6 → 0.8`;
- временный проверочный кандидат и записанный канонический файл дали одинаковый итоговый SHA256.

## Ограничения

Существующий `manufacturing/current/` построен из прежней PCB `9e10942d…` и после этого изменения устарел. Он не является комплектом для заказа; CAM, сверловку, PDF, BOM/позиции и manifest нужно пересобрать только после закрытия парности SCH/PCB. R108/C109, пуск, SOA, силовые расчёты, прошивка и физические испытания этим шагом не закрыты.
