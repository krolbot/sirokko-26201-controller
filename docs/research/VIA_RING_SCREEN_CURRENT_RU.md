# Предварительная проверка увеличения площадок переходов Sirokko

Статус: DRAFT / НЕ DRC / НЕ ПРИМЕНЕНО К PCB / НЕ ДЛЯ ЗАКАЗА.

## Исходные данные

Живое чтение канонической PCB через KiCad MCP list_pcb_traces: 633 прямых сегмента и 145 переходов. Текстовая и структурированная формы ответа совпали полностью. Инвентаризация: 103 перехода 0,60/0,30 мм; 35 — 0,80/0,40 мм; 6 — 1,00/0,50 мм; 1 — 0,70/0,30 мм. list_pcb_nets отдельно подтвердил числовые коды цепей в текущем чтении.

Проверяется одновременное увеличение всех 103 площадок 0,60 → 0,80 мм. Отверстия 0,30 мм, центры и цепи не меняются. Для предварительной отбраковки принят зазор 0,20 мм. Результат зависит от этого порога; это не самостоятельное назначение или изменение правил KiCad.

MCP не предоставил SHA256 исходной PCB или UUID объектов. Поэтому этот результат нельзя использовать как готовый список редактирования: исполнитель должен связать координаты с UUID и свежим хешем своего источника. Совпадение числа объектов не доказывает побайтовую идентичность файла.

## Метод и результат

Для перехода и прямого сегмента чужой цепи на общей медной стороне:
`зазор = расстояние(центр перехода, конечный отрезок осевой линии) − радиус площадки − ширина дорожки/2`.
Для двух переходов чужих цепей с общими слоями:
`зазор = расстояние между центрами − радиус первой площадки − радиус второй площадки`.
Единицы всех размеров — мм. При проверке пары одновременно учтены оба увеличенных радиуса; одинаковые цепи исключены по текущему чтению. Численная граница сравнения — 0,000001 мм, она не является производственным допуском.

- Уже в ограниченной проверке «дорожки + переходы» обнаружены 46 направленных конфликтных взаимодействий, затрагивающих 27 разных переходов.
- 46 — не число физических нарушений native DRC: пара переходов учитывается с обеих сторон, а несколько сегментов одного изгиба дают несколько взаимодействий.
- Остальные 76 кандидатов этой частичной проверкой не отвергнуты, но НЕ ПРИНЯТЫ.
- Площадки компонентов, заливки, контур, сверловочные зазоры, маска и прочие правила в расчёт не включены. Нужна полная native-проверка каждого принимаемого набора с refill.

Показательный отрицательный контроль — соседние переходы /FUEL_CMD (252,7575; 26,2465) и /GLOW_CMD (253,5692; 26,4290). Расстояние центров 0,831963425 мм. Исходный зазор двух площадок Ø0,60 мм: 0,231963425 мм; при увеличении обеих до Ø0,80 мм: 0,031963425 мм. Исходная пара проходит принятый порог 0,20 мм, увеличенная — нет. Это расчёт по CAD-координатам, не измерение изготовленной платы и не замыкание исходника.

## Инженерное решение

Не применять сплошное увеличение всех 103 площадок. Сохранить ограничения текущей задачи: принять только совместно проверенный набор, конфликтующие места вернуть по UUID и фактической геометрии для локального решения. Не ослаблять правила и не менять отверстия, цепи или расположение переходов для сокрытия конфликтов. Этот расчёт сам по себе не изменял PCB, не подтверждает новую публикацию и не закрывает окончательную проверку связности.

Полные исходные взаимодействия и минимальные зазоры кандидатов находятся в VIA_RING_SCREEN_CURRENT.json. Рабочий файл PCB остаётся единственным; альтернативная PCB или архив не создавались.
