# Sirokko — исправление BIAS и входного фильтра двух MAX31856

DRAFT / NOT FOR ORDER / NO POWER / NO FLASH / NO FIRE.

## Предмет и основание

Проверен действующий корневой netlist на Lab, после принятой замены C104. Исходная PCB SHA256 1905414e7b0e475155571546124c7522033b31af004a7bede8ba72e2ff1d1517; root SCH 8857489e2cb666875fa123cc92b904645efd90dff04d8d8b168e6403f9691649. Эти два файла до настоящего изменения соответствовали опубликованной ревизии 0a9eeddbae863eacb8e9d21d5c40d7c56fe0b4ad; PCB и power SCH прочитаны по exact raw commit, SHA совпали.

В обоих каналах обнаружена одна и та же ошибка:
- U9.2/BIAS и C9.1 были отдельной сетью TC_EXH_BIAS, без DC-соединения с U9.3/T−.
- U10.2/BIAS и C14.1 аналогично были отделены от U10.3/T−.
- C9.2 и C14.2 были подключены к GND. Поэтому конденсаторы 0,1 мкФ не выполняли функцию дифференциального фильтра между T− и T+.

BIAS — выход смещения термопарных входов, номинально 0,735 В, а не отдельный вход питания. Для принятого включения он должен задавать синфазное напряжение через T−. Отдельный конденсатор BIAS–GND не создаёт этого DC-пути. Нельзя исправить отсутствие схемного соединения программной калибровкой или настройкой типа термопары.

Первоисточник: Maxim Integrated, MAX31856, документ 19-7534, Rev 0, February 2015, 30 страниц. Прочитаны pin description, типовая схема страницы 1 и описание обнаружения обрыва/таблица 4 страницы 14. Страница 1 визуально проверена: BIAS соединён с T−, 0,1 мкФ между T− и T+, по 0,01 мкФ от каждого входа к AGND. Это историческая редакция, не утверждение о последнем издании.

Официальный текущий URL https://www.analog.com/media/en/technical-documentation/data-sheets/MAX31856.pdf вернул страницу отказа доступа; она не принята за паспорт. Открытая копия документа изготовителя прочитана по https://raw.githubusercontent.com/evsviridov/MAX_31856/master/MAX31856.pdf ; SHA256 PDF 385702a94433d75e89ad4f04ab197fd73ab166a21fbd453fcedd9a9821acc662. Чужой PDF в репозиторий проекта не включать.

Дополнительное независимое пояснение изготовителя: https://ez.analog.com/data_converters/a/documents/do12561/can-i-connect-bias-to-tc-instead-of-tc--on-max31856-will-this-affect-accuracy . При BIAS на TC− напряжение TC+ равно VBIAS + Vdifference. Эта заметка подтверждает назначение смещения, но не заменяет полный паспорт.

## Внесённое исправление

Сначала изменена полная изолированная копия; после проверки в canonical перенесены только корневая схема и PCB. Ни компонентов, ни внешних клемм, ни GPIO не добавлено и не удалено.

Теперь выхлопной канал:
- U9.2/BIAS, U9.3/T−, J10.2, C11.1 и C9.1 — одна сеть /TC_EXH_TM.
- U9.4/T+, J10.1, C10.1 и C9.2 — одна сеть /TC_EXH_TP.
- C9 0,1 мкФ подключён между T− и T+; C10/C11 по 0,01 мкФ на землю сохранены.

Воздушный канал:
- U10.2/BIAS, U10.3/T−, J11.2, C16.1 и C14.1 — одна сеть /TC_AIR_TM.
- U10.4/T+, J11.1, C15.1 и C14.2 — одна сеть /TC_AIR_TP.
- C14 0,1 мкФ между T− и T+; C15/C16 по 0,01 мкФ на землю сохранены.

У C9/C14 изменён только описательный Value на `0.1uF X7R 16V TC differential filter`; MPN GRM188R71C104KA01D и посадки сохранены. На PCB соединены соседние выводы 2–3 каждого MAX31856, подведены новые дорожки к C9.2/C14.2. У C9 переработаны два конкретных GND-сегмента, ранее проходивших через его площадку 2. Восстановлена связь местной земли короткой B.Cu-перемычкой с двумя переходами 0,6/0,3 мм: (32,8625;33,75) и (28,2;33,75) мм. Это необходимый возвратный путь после изменения фильтра, не попытка спрятать разрыв зоны. Остальные новые сигнальные дорожки F.Cu; ширина новых участков 0,25 мм.

## Выполненная проверка

- Полный корневой XML netlist содержит 291 назначение `(reference,pin)→net`. Изменились ровно шесть: U9.2/C9.1 с BIAS на EXH_TM; C9.2 с GND на EXH_TP; U10.2/C14.1 с BIAS на AIR_TM; C14.2 с GND на AIR_TP. Все прочие назначения неизменны.
- Вся структура всех 86 footprints совпала после учёта только разрешённых Value и указанных pad-net изменений. Положение, ориентация, отверстия, размеры площадок, номера, UUID, прочие поля сохранены.
- Из прежних медных объектов удалены ровно два адресных GND-сегмента; остальные 1112 объектов сохранили геометрию, с необходимым объединением имён BIAS→TM. Добавлено 11 сегментов и два via. Нет изменений контура, графики и правил/контуров зон; фактическая заливка пересчитана штатным KiCad.
- Физическая связность проверена через native BuildConnectivity/GetConnectedItems, по полным UUID площадок. Охвачены 338 физических pads; подтверждены симметрия и замкнутость групп. Все 2552 обязательные прежние пары сохранены. Из старых требований исключены только отношения переносимых C9.2/C14.2 к прежней земле; это намеренное переподключение, не разрешение потери остальных GND-пар. После изменения 2570 физических пар.
- Адресно подтверждены U9.2↔U9.3, U10.2↔U10.3 и обе стороны C9/C14 к нужным термопарным входам. T+ и T− не замкнуты медью.
- Отрицательный контроль на отдельной копии: удаление ровно двух новых перемычек BIAS–T− вызывает два unconnected, DRC exit 5; native проверка меняется с [true,true] на [false,false]. Отрицательная PCB не принималась и удалена.
- После принятия canonical: KiCad CLI 10.0.7, свежий DRC с --all-track-errors --schematic-parity --refill-zones --severity-all --exit-code-violations: exit 0, violations 0, unconnected 0, parity 0, ignored_checks []. Свежий корневой ERC: exit 0, нарушений 0; прежние исключённые типы single_global_label/four_way_junction/simulation_model_issue/footprint_filter остаются явно видимыми и не объявляются проверенными ERC.
- Новый BOM штатно экспортирован. SVG F.Cu/шелкография/контур экспортирован, координаты связаны с реальной C9 Reference; увеличенный PNG обоих узлов визуально проверен. Изображение — обзор разводки, не подтверждение работы и не размерный шаблон.

Текущая принятая PCB: 870 segments, 255 vias, 86 footprints, 25 zones. Это фактическое состояние текущего файла, не исторические счётчики предыдущих ревизий.

## Что ещё не доказано

Исправлено включение двух измерителей, но не квалифицирован весь термоканал. Для выпуска ещё требуются бюджет погрешности термопары/преобразователя/холодного спая, тепловой градиент клеммы–ИС, проверка заземления фактических зондов, помехи и время обнаружения отказа. Не считать произвольную заземлённую термопару совместимой без проверки её синфазного напряжения. Настройка детектора обрыва зависит от сопротивления проводов и входной ёмкости; в автоматическом режиме паспорт предусматривает тест раз в 16 преобразований — это не непрерывная мгновенная защита. Выводы FAULT U9.13/U10.13 остаются NC, следовательно прошивка должна читать статус по SPI, а не ждать несуществующего GPIO FAULT.

Разрешение кода 0,0078125 °C не равно точности. Порог показания 600 °C сам по себе не гарантирует, что реальный горячий спай не превысит 600 °C: необходимо учесть погрешность, задержку и тепловой выбег. Здесь новый эксплуатационный порог не назначен. Нет измеренного доказательства запуска, обнаружения обрыва, продувки или безопасного горения.

Ровно K1/K2, внешнее управление HC160 через J29, GPIO18/GPIO21 NC, отсутствие экрана/кнопок/энкодера сохраняются. USB только для сервисной прошивки; рабочее питание ESP32 от Sirokko. Firmware HOLD, запреты питания/физической прошивки/огня и запрет заказа в производство не сняты. Старый manufacturing-комплект не содержит этой правки и должен быть заменён согласованным новым DRAFT-комплектом до использования.
