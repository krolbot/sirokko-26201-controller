# Кандидат Sirokko 262.01 без P24 — отчёт 2026-11-01

## Результат

Проверенная инженерная дельта перенесена в действующий канонический проект `hardware/kicad/`. Удалена только цепь отдельного контроля наличия 24 В; остальные узлы сохранены. Статус всего проекта остаётся `REVIEW REQUIRED / NOT FOR ORDER`.

Из PCB удалены восемь посадочных мест:

- `U20`;
- `Q20`;
- `D20`;
- `R120`;
- `R121`;
- `R122`;
- `R123`;
- `C28`.

Также удалены пять внутренних сетей `/P24_PRESENT`, `/P24_BASE`, `/P24_SENSE_N`, `/P24_SERIES_MID`, `/P24_ZENER_K` и обслуживающая удалённые выводы медь. Всего манифест содержит 102 удалённых объекта: 8 посадочных мест, 71 сегмент и 23 переходных отверстия. Один сегмент `+3V3` укорочен до сохранённого ответвления `R1.1`, чтобы не оставить хвост P24 и не разорвать `J1.2—R1.1`. `J1.6` переведён с `/P24_PRESENT` на штатную NC-сеть KiCad.

## Доказательство сохранности

Машинная сверка исходной и новой PCB прошла полностью:

- удалены ровно UUID из манифеста;
- новых UUID не появилось;
- все оставшиеся посадочные места и площадки сохранены побайтно по нормализованным записям, кроме объявленного изменения сети `J1.6`;
- вся оставшаяся медь сохранена, кроме объявленного укорочения одного сегмента `+3V3`;
- связность между оставшимися площадками совпадает с исходной;
