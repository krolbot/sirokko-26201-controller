# Реализация прошивки Sirokko 262.01

Разработка разрешена прямым сообщением пользователя 2026-11-06: «Можно делать прошивку». Прежний HOLD разработки снят. Аппаратные файлы, GPIO-карта и условия физических испытаний не меняются.

## Согласованный объём

Автоматическая калибровка без подтверждения каждого шага; короткий KEY0 — STOP и отрицательное сообщение о горении. Ручной режим и PI-регулирование без гашения по комнатной уставке. Меню энкодера и TFT; AP/браузер без облака; отложенное выключение; OTA. Сохраняется ранее согласованный одноразовый относительный отложенный пуск.

## Программные решения этой реализации

- Уставка 15–30 °C, шаг 1 °C, при каждом включении 15 °C без автопуска. Ручной уровень — 5 п.п. от максимума, с ограничением нижней откалиброванной границей. До получения температурного диапазона разрешён только исходный настроенный опорный режим, не произвольный низкий PWM.
- PI: Kp=0,05 рабочего диапазона/°C, Ti=1800 с, Tt=300 с, зона интегратора ±0,2 °C; фильтр и формирователь 10 с. Раздельные начальные темпы 0,005 рабочего диапазона/с. Это перенесённые настройки исследования, не огневые измерения.
- Таймер выключения: 0 (выключен) либо 1…10080 минут, шаг 1 минута, монотонное время. Сохранённая длительность применяется при новом START; редактирование настроек не перезапускает текущий отсчёт. Отдельное действие «Выключить через» ставит/заменяет срок от текущего момента, 0 отменяет его. Истечение означает отсечку топлива и начало охлаждения. STOP/авария приоритетнее. После сброса таймер не восстанавливается.
- Полярность KEY0/энкодера active LOW, подавление дребезга — программные настройки. TFT ST7789 и GPIO взяты из TFT24_INTERFACE_RU.md; разрешение/ориентация покупного исполнения остаются настраиваемыми, не выдаются за измеренный факт.

## Граница физически неизвестного

Доступны только две выходные температуры, DS18B20 помещения, время и команды. Встроенная калибровка исследует температурно-динамический диапазон внутри явно заданной области испытаний, не спускается до погасания и не доказывает CO/дымность/чистоту горения. Числа безопасного розжига, перегрева, охлаждения и нижней границы исследовательской команды неизвестны для собранного экземпляра: их не подменяют демонстрационные векторы тестов. Настройки процесса вводятся отдельно; до их наличия топливо запрещено. Такой ввод не является подтверждением каждой ступени калибровки и не превращает числовую валидацию в огневую квалификацию.

## Приёмка

Выполняются реальные host-тесты, сборка ESP-IDF v5.2.3 для ESP32-S3 N16R8, проверка интерфейсов и конечных образов. Программные результаты, стендовая имитация и физические испытания отмечаются раздельно. Полная целевая компиляция/линковка ESP-IDF v5.2.3 завершилась exit 0, сформирован ESP32-S3 `.bin`. Родитель повторно запустил общий host suite; интеграционный цикл калибровки дополнительно прошёл ASan/UBSan. Проверены краткий STOP и его событие, таймер во время калибровки, плохой датчик, постоянные свежие температуры, квантование PWM при 20 мс, охлаждение перед сохранением и отказ записи. Это программная приёмка, а не физическая работа AP/TFT/OTA-reboot/горелки. Независимый разбор выявил две воспроизводимые ошибки — потерю maintenance перед выбором OTA-слота и обрезание HTTP body по NUL. Обе исправлены, отрицательные сценарии до исправления падали и после исправления прошли. Финальный общий host suite включает 9 наборов ядра/панели/OTA activation и полный web/OTA; целевая сборка после исправлений завершилась exit 0. SHA-256 в браузере проверен также без Web Crypto, для обычного HTTP AP. Готов программный комплект версии 1.0.0-dev1; Git-публикация, физическая загрузка и огневая квалификация в этот результат не входят.
